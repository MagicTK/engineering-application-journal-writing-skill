# Run identifiers and process trajectories

## Fictional reading check

A cyclic pressing experiment assigns each of four material lots to both of two tooling conditions. Within a condition, one complete stroke is recorded for each lot. Each stroke yields ten overlapping windows. The author writes that eight independent lots supplied eighty test cases. How should the experimental units be reported?

There are four material lots, eight stroke trajectories, and eighty windows. Lot and tooling condition together distinguish a trajectory. A test of transfer to another lot should keep both strokes of each lot together. Window-level errors can be tabulated for a question about individual windows. Uncertainty about transfer to a new lot must account for the shared lot.

If a different experiment gives each stroke a globally unique identifier, the identifier alone can count trajectories. The recorded production hierarchy and transfer question determine the grouping. A repeated integer in a table, by itself, establishes neither statistical dependence nor independence.
