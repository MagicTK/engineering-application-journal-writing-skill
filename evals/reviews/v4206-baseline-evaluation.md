# Terminology-Lookup Baseline Review

The actual v4.2.5 library has one mixed core-record table per language. The maintenance snapshot matches the retained v4.2.5 export exactly. Each table has 62 records; a pre-edit check finds zero of the six planned lookup groups. This is a document/navigation baseline, not a failed language-model or scientific test.

The scoped revision groups existing rows mechanically and preserves their bytes, as well as all subsequent role contrasts and Chinese-wording material. The actual post-edit check finds six groups and the same 62 records per language. No definition, source evidence, unresolved limit or translation status was upgraded. An independent frozen-source review is still needed; grouping and hashes alone do not demonstrate scientific validity, field prevalence, lookup speed or general writing improvement.

The question-based grouping is intentionally nonexclusive and selects reading, not a method for an industrial problem. It must retain the distinctions between task outputs, observation arrangements, data-use phases, training signals and actual operations. Local word queries should not require reading the entire catalogue.
