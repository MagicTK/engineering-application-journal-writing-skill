# 4.1.6 Terminology-Admission Evaluation

## Procedure

One fresh responding context read the frozen 4.1.5 root Skill and relevant references and answered four fictional author requests. It received no private manuscripts, corpus PDFs, scoring rubric or earlier responses. The same respondent then reread the frozen 4.1.6 root Skill and terminology references and answered those four requests again. Two further requests were written after the source freeze and answered in that same context.

The inherited model identifier was not exposed by the runtime. The maintainer reviewed the returned content semantically. This is one fresh responding context, not six independent respondents or an independent second grader. It tests the root Skill with its terminology references, not separate invocation of every specialist entrypoint.

## Evidence Limits

The published terminology ledger contains seven English base-term checks and four Chinese pairing checks. This is a partial audit. Neither the 40-paper index, a full-text scan nor these six fictional responses establishes that every existing name or translation has passed admission. Different sensing tasks may support the same base operation, but complete compound names and claimed engineering properties require their own scope checks.

The extractor's seven deterministic tests cover page contexts, reference-region flags, literal matching and file-identity behavior. A real-PDF smoke check also retained different papers with the same filename and skipped a byte-identical duplicate. These are candidate-discovery checks, not automated synonym validation, scholarly-work deduplication or terminology admission.
