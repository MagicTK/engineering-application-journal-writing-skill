## Separate Maintainer Checks

- Six focused program tests cover exact counts, summaries, the saved table,
  missing/duplicate outcomes, invalid inputs and preservation of an existing
  output directory. The complete suite has 101 passing tests and 14 bilingual
  entry-pair structural checks. These do not replace behavioral evaluation.
- The saved plot was visually inspected. Its 75-90% axis range is explicit;
  individual markers, mean and sample-SD bars are distinct. A local Markdown
  preview was checked at 1120-pixel desktop and 390-pixel mobile widths; images
  loaded and no document-level horizontal overflow occurred. Code blocks can
  scroll. This was not a live GitHub rendering check.
- Initial plotting produced a font-cache warning; a task-local cache resolved
  it. A local preview server was disallowed, so the preview used in-memory HTML.
  The bundled Playwright browser was absent; the installed Chrome was used with
  an isolated temporary profile after permission was granted. No browser package
  was downloaded and no logged-in browser profile was read.
- Public example inputs were authored for this demonstration. No real paper,
  result, confidential process detail or private manuscript image was used.

## Limits

This is an optional fixture-specific example, not a new general evaluator,
training backend or universal experimental recipe. The generated numbers show
arithmetic and traceability; they do not establish industrial performance,
generalization, stability or a population-level uncertainty estimate. Existing
scientific guidance and historical evaluations retain their own evidence scope.
No controlled before/after Skill improvement or whole-suite scientific
certification is claimed.
