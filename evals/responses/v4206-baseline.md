# Actual Table-Layout Baseline

This is a deterministic document inspection, not a baseline language-model response. Before grouping, each language has one mixed core table containing 62 existing records. The actual navigation check finds zero of the six planned purpose-based groups. Every existing row and the downstream context/Chinese-wording tail are fingerprinted before changes. The baseline does not fail a scientific test and is not evidence of poor underlying definitions.

After mechanical regrouping, both languages retain all 62 core records and the protected tails byte-for-byte, with six selective reading groups each. This shows preservation and the requested document structure, not measured lookup speed, general writing improvement or full-corpus certification.
