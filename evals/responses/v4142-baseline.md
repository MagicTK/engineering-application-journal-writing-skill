**A**

方法说明（39词）：

> An encoder and classifier are trained on labeled historical source data. Initialized from these weights, source-free adaptation updates selected parameters of the target encoder and classifier using only unlabeled target samples while retaining the same three-class fault label space.

作者意见：
- 两种说法均不成立。Source-free 约束目标适应阶段的源数据访问，不要求分类器完全冻结；应保留题设中的实际参数更新。
- 三类故障均已在源阶段通过有标签数据学习。目标标签不可用说明目标适应无监督，不足以改称未见类别意义上的 zero-shot。正确的历史监督训练不是泄漏。
- Source-free 不能直接推出因果在线预测，也不能推出形式隐私保证。前者需要明确预测时的信息边界和更新顺序；后者需要相应隐私机制与保证，仅不传原始源样本并不足够。

**B**

缓冲构造说明（24词）：

> The pseudo-source bank stores 100 high-confidence samples selected from the existing unlabeled target pool, each paired with a pseudolabel generated by the source model.

作者意见：
- 缓冲名称不能推翻数据来源事实：这是目标池派生的伪标注缓冲，不是原始源样本回放。因此，不能仅凭该名称否定源数据不可用的设定。
- 这100个是已有目标池的子集，没有新增独立采集样本，也没有新增真实人工标签；不能在原池独立样本数之外再加100。
- 尝试7个阈值本身不自动构成泄漏。但用同一测试集真标签选最高准确率，属于测试标签参与模型选择，即使这些标签未进入梯度更新也一样。该最高分不能称为“无监督模型选择后的无偏测试性能”。这与是否访问原始源数据是两个不同问题。
- 作者应保留原始分数，核实并如实披露7个设置及择优依据。现有描述没有提供未参与选择的独立评价证据，不能补写已经实施的验证集或调参程序。

**C**

摘要（174词）：

> Changes in operating conditions degrade process fault classification, while restrictions on sharing historical process measurements prevent target sites from accessing source training data. We develop a source-free method that adapts an encoder pretrained with a classifier on labeled source data, using only source-model weights and an unlabeled batch of target measurements. Temporal consistency between predictions for adjacent windows from the same operating sequence determines which target pseudolabels are selected. Selected pseudolabels supply the supervision for target encoder updates, adapting its representation to target measurements while keeping the source classifier fixed. After adaptation, the encoder and classifier assign each sample in the target batch to one of the three fault classes learned during source training. Fixed cross-condition comparisons on a simulated benchmark and real production measurements show higher overall classification accuracy than the frozen source model and existing source-free adaptation methods. Under the largest operating-condition shift, however, recall is lower for one minority fault class. The findings support batch fault classification under source-data sharing restrictions while revealing a class-level trade-off within the observed accuracy gains.

贡献候选（41词）：

> Temporal consistency between predictions for adjacent windows within the same operating sequence selects target pseudolabels that guide encoder updates with a fixed source classifier, enabling batch fault classification from source-model weights and unlabeled target measurements when source measurements cannot be shared.

作者意见：
- 摘要连接了工程约束、历史监督训练、目标伪标签选择、编码器更新和最终批量分类；没有把时间选择写成额外的推理模块或源／目标特征融合。
- 整批目标可见、超参数预先固定、真标签仅用于最终评分，应在实验设置中明确。这是题设允许的批量适应，不应改写成逐样本因果在线预测或未知类识别。
- 保留整体准确率收益及少数类召回率权衡；不新增显著性、现场部署或形式隐私结论。召回率降低的具体比较对象和幅度未给定，正文应按实际证据核实。
- 贡献候选描述的是实际选择到学习的设计，新颖性仍须作者对照前作确认。整体方法比较不能单独证明时间选择机制的独立增益，也不能据此捏造消融结果。
