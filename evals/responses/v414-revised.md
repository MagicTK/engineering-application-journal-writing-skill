**`input-conditioned-grouping`**

:::writing{variant="document" id="84163"}
**Abstract.** Process diagnosis can use the fixed production-unit organization of measured variables while computing relationships from each input. We propose a framework that couples input-dependent grouping within units with knowledge-guided aggregation across units. A standard shared temporal encoder produces one feature vector per variable. Within each unit, soft assignments computed from the current features determine group averages, whose context updates the variable features. Averages of these updated features form unit representations for similarity-weighted aggregation, with the given process topology biasing the aggregation scores. The resulting context for each unit is integrated into its variable features through sigmoid gates conditioned on both the receiving feature and the unit context. The classifier combines the context-enriched features with an unchanged copy of the encoder outputs, retaining individual-variable information alongside relational context. Assignments and gates are recomputed for each test input while trained parameters remain frozen. Independently trained models outperform the comparison methods on a simulator benchmark and held-out production campaigns. Component-removal tests support the grouping and topology-bias roles, providing evidence for the proposed coupling of fixed process structure and input-dependent relational computation.

**Contribution**

**Methodology Overview.** Measured variables retain their given production-unit membership. Unit averages of those updated features then enter similarity-weighted aggregation, with the given topology bias added to the aggregation scores. Each local variable feature and its unit's aggregated context jointly determine a sigmoid gate that integrates the context into that feature. The classifier combines the resulting variable features with the reserved encoder outputs. Test-time assignments and gates are recomputed from each input with all trained parameters frozen.
