## First pass for a group of drafts / 组内多稿初筛

Use **one row per draft**, not one draft per model family. Keep unpublished titles and data in the group's private copy. Use a local ID in shared progress summaries. Repeat only for genuine secondary constraints that change the prediction task or evaluation.

| Draft ID | Decision, unit, deadline | What is missing/changes, for whom and when? | Nearest comparison: source + page/table; what remains unresolved? | Candidate method; changed object → recipient | One decisive experiment, one figure, limiting fact | Next edit / owner |
|---|---|---|---|---|---|---|
| Synthetic example | Estimate outlet concentration at sample draw | Valve history is available; the reference assay returns later | P34 pp.6–7: downsampled and multirate soft sensors are distinct comparison routes; isolate the role of fast readings here | Keep acquired fast readings → input to concentration estimator | Same run split and assay times; matched input-treatment control; show draw/report timestamps. Check actual analyzer release delay. | Author revises gap after lab confirms availability |

For the selected draft, trace a single claim across sections: **abstract** (bounded outcome), **introduction** (nearest prior capability and unresolved decision), **motivation** (concrete ambiguity), **formulation** (allowed inputs, target and time), **contribution** (supported advance), **method** (input → operation → output), **experiment** (what comparison could contradict it), **discussion** (where evidence stops). A passage about a paper's experiments is not evidence that your study ran the same comparison.
