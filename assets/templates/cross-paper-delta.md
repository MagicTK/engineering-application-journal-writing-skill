# Cross-Paper Contribution Delta

| Item | Closest team paper | Closest external work | Proposed study |
|---|---|---|---|
| Identity / method pages / code version / actual reading evidence | | | |
| Task and operating assumptions | | | |
| Data version and information access | | | |
| Retained operations, reused code/modules/data and attribution | | | |

| Unadapted direct-transfer baseline | | | |
| Core mechanism and supported capability | | | |
| Claims already supported elsewhere | | | |
| Substantive change and isolating evidence | | | |

- Independent question/capability, in one sentence:
- Overlapping claims and attribution needed:
- Evidence needed to distinguish the change, including a naive composition control when a coupling claim requires it:
- Inspected method sections / checked experiment tables / code reproduction scope (record separately; leave unchecked work explicit):
- Decision: retain / revise / merge / defer / drop standalone claim:
- Reason; unresolved source identity or data fact:

Use only relevant fields; repeat the source record for distinct inherited mechanisms when necessary. A change in name, wording, random seed, or arbitrary label proportion alone does not establish a separate scientific contribution.
