# 按语义和场景选择术语

与[通用术语库](engineering-application-terminology-bank_CN.md)配合使用，不是机械替换词典。来源编号对应[已发表文献索引](published-evidence.md)。文献有用例只能说明这个词可以成立，不能证明它符合当前方法。作者偏好留在具体论文的术语表中。

## 决策顺序

1. 确定对象：物理量、观测、样本、隐特征、工况、状态，还是计算操作。
2. 核对上下句、定义、公式及输出去向，不能仅凭模块名推断功能。
3. 搜索相近工程任务中的具体搭配；排除参考文献标题，并辨别名词与动词。
4. 区分：正确、需定义、作者偏好、含义不清、科学含义不符、证据不足。
5. 必要时给出原句、位置、局部改句和理由，不做全篇自动替换。

没有搜到只表示“在本次检索语料中未发现”，不等于禁止使用。词频不证明科学正确性。配套脚本只产生待核查候选。

通用机制、模块、方法和操作名称按[双来源准入及中文独立核查](engineering-application-terminology-bank_CN.md#零专业名称准入与译名核查)执行。单篇只能确立该论文自己的定义，不能证明通用类别。保留来源归属、作者提出的准确专名和普通功能描述；熟悉的基础词不为任意组合限定词背书。

## 数据对象

| 术语 | 适用对象 | 必须区分 |
|---|---|---|
| process variable / measured variable | 温度、压力、流量等测量或控制量 | 隐空间特征不等于物理变量 |
| quality variable | 产品或过程质量的测量目标 | 类别标签不一定是连续质量量 |
| feature / feature representation | 输入描述量或编码后的特征 | 改进特征不等于改变测量变量 |
| channel | 已说明与变量、信号对应关系的模型轴 | 不默认所有模型一变量一通道 |
| sample | 窗口、钢板、批次、周期等学习或评价单位 | 数据库一行不一定是一个独立样本 |
| instance / bag（多实例/多示例学习中） | 明确定义的成员表征及其组成的包；成员可以是时间点、子序列或学习得到的特征 | 内部实例不自动是独立采集或逐一标注的生产样本，包级监督也不自动证明细粒度定位 |
| observation / measurement | 一个观测值、向量或观测事件 | 观测单位与样本单位可能不同 |
| record | 真正的数据库、日志记录或关联对象 | 不用来随意替代训练样本 |
| attribute | 故障语义属性、图节点属性、元数据字段 | 不作为过程测量变量的默认名称 |

训练和测试数量通常写 `training samples`、`test samples`。只有真实存在训练与模型选择的数据池时才写并解释 `development set`，不能用改名暗示做过验证集实验。将 records 改成 samples 前先确认二者是否同一单位。

P05、P06 和 P29 的 attributes 用于零样本故障语义，P20 用于图节点属性；P29 明确区分结构化故障描述、传感器测量及其文本化表示。这些合法用法不妨碍物理测量优先用 variables。动词 attribute 与此不是一回事。

## 状态、工况与模式

| 术语 | 合理含义 | 核查问题 |
|---|---|---|
| operating condition(s) | 负荷、设定值、速度、原料等运行条件 | 是否确实指可辨识的工况，而非隐向量？ |
| operating mode | 定义明确的离散运行模式 | 模式划分、标签从哪里来？ |
| operating state / operational state | 过程、系统或局部单元当前的运行表现或状态 | 是物理状态、推断状态还是编码？ |
| process state | 物理、监测或数学定义的过程状态 | 上下文是否给出明确对象？ |
| latent state / hidden state | 内部数学表示 | 是否误写成已验证的物理状态？ |
| prototype | 真正存在的代表向量、样例或中心 | 模型是否有原型机制？ |

P04 有 process state 的实际用例；P16 有 operational state；P10 研究 operating conditions。这不是常见程度排名。不能只为流畅把 state 换成 condition：连续变化的局部特征并不自动构成离散工况。`local operational state` 需要与真实的局部自适应机制相符，也不等于已识别物理状态。没有原型机制，不引入 `prototype state`。

确有原型时，说明其代表对象和构造方式：按类别计算的特征均值、选取的代表样本、独立优化的参考向量不能互换。P46 与 P47 都从有标签特征计算类别代表，但后续用途不同。经过可学习编码器再求均值，不等于该均值本身是独立训练参数；类别代表也不等于实测运行状态。应承接查询匹配或训练损失等真实用途，不能默认每个原型都直接用于分类，或每类必定只有一个原型。基础名称与中文译法的核验范围见[术语配对记录](engineering-application-terminology-bank_CN.md#九已核验核心名称与未完成范围)。

P79 p.9用分类器权重向量定义源类别原型，并在目标表征学习时保持它们固定。保留该归属明确的构造，不改写成缓存的源样本均值。用作类别参照的模型参数、源实例回放缓冲，以及由目标测量构造的缓冲，是不同保留对象。

学习得到的模糊状态（P07）、离散运行模式与动态模型中的状态向量各有定义，不能因为都有state就互换。状态向量可以是统计潜在表征，也可以有已建立的物理含义，不能仅由状态空间形式决定。process disturbance是扰动过程行为的输入或事件，也不等于获取测量时的背景工况。

状态空间描述须连清转移模型、观测模型和最终输出。P34 pp.2-6估计潜变量用于质量预测，P73 pp.2-6估计动态/静态潜变量用于监测统计量；潜坐标及其协方差不自动是实测物理状态或故障概率。明确映射支持的物理状态表述仍可保留。P73 p.5指出标准化前的参数化不唯一，归一化本身不使潜坐标获得物理可辨识性。

`dynamic`、`adaptive` 先说明**改变了什么**。注意力、分组分配或门控可以随每次输入变化，而训练参数保持固定；循环状态、滚动参考统计量也可以更新而不重新拟合参数。在线学习或测试时参数适应是另一项主张，需要实际更新规则和获准的信息。P24 的时间间隔加权与 P04 的滚动异常评分分别展示不同的变化对象，不能仅凭名称判定持续学习。直接写明已验证的操作，例如 `input-dependent grouping`，但不禁用定义准确的 adaptive 表达。

Kalman状态预测/校正与EM参数拟合改变的是不同对象。核查所条件化的观测范围：t时刻滤波使用截至t已允许获得的观测，平滑可利用更后时刻的观测修正该状态。训练序列上的前向/后向E步（P34/P73）不等于当前预测读取了未来；按实际延迟发出的固定时滞回顾估计也可合法使用已发布的后续测量，但不能报告为零延迟结果。摘要、方法分别写清预测时状态递推、真正的参数更新及最终质量量/监测决策。[基础名称配对](engineering-application-terminology-bank_CN.md#九已核验核心名称与未完成范围)不认证所有神经、自适应或多速率完整专名。

发出较晚不自动证明用了后续信息：所有输入可能早在目标时刻就已获得，只是计算结束较晚。须将实际测量发布时间与所声称的决策截止时间比较。把更晚发布的输入用于声称更早已作出的决策，属于信息访问违规；若没有后续输入却把延迟计算报成即时完成，则仍是延迟/报告问题，但不能据此认定未来信息泄漏。仅写“发出前已获得”不能说明实际用了哪一个最新观测。

适应不一定使用梯度更新。P05用无标签测试样本的预测调整语义参照向量，保留网络前向输出；应说明改变的对象和可用数据。使用整个目标批次，与只访问过去及当前观测的因果数据流，信息条件不同。保留来源自提的adjustment名称，不把任意阈值或参照向量变化都称为增量参数学习。

区分目标侧拟合与评价期更新：冻结骨干可接收另一组件的校正，该组件先前经过拟合，之后两个网络的可训练权重固定而统计量仍可改变。后期统计只用控制变量，不等于早期拟合损失从未使用传感测量；已确认健康的校准样本即使没有故障类型标签，也保留其健康状态信息。正文正面写清阶段，参照[已核测试时调整范围](engineering-application-terminology-bank_CN.md#九已核验核心名称与未完成范围)。按解析式赋值的偏置也可能是模型参数，不能因没有反向传播就说该参数没变。

对**source-free domain adaptation**，明确在哪个阶段源样本不可访问。源训练模型可以保留有标签历史知识，而目标侧只用无标签测量进行适应（P78/P79）。记录提供哪些模型信息及更新哪些组件；冻结整个分类器是一种设计，不是定义。源数据访问、目标标签访问、两域类别重合与预测时序是不同维度。不能只因目标没有标注，就把源阶段已学类别的适应改称零样本，或由source-free推出因果在线流。

对**domain generalization**，区分仅用源数据开发模型与在未见域上预测（P50 p.2；P99 pp.4,7）。预测仍要读取允许的测量输入；在当前窗口内按固定规则归一化，与用整个无标签目标池重新拟合持久统计量不同。后者即使不更新网络权重，也改变了访问条件；明确声明的目标适应或混合设置可以合法，但不是相同的纯源侧开发比较。新工况下类别仍相同，不证明识别未见故障；若来源用zero-shot transfer表示未见域迁移，保留其明确定义，不默认为类别级零样本诊断。

样式参照特征中的target须沿来源核查：P50 p.3背景公式的target表示参照样式，单凭此词不能认定读了保留目标域。表征不变性目标也不证明物理因果或任意变化下完全相同的特征。记录实际源域数量、选择数据及变化对象，不把一种多源实现变成DG普遍要求。

沿实际来源核查pseudo-source对象：目标样本加伪标签构成的缓冲，不会因名称变成采集的源数据，也不新增独立测量。正文正面说明已核实的数据访问约束。若提出更强隐私主张，再核实相应机制与范围；仅不传原始源样本不能认证形式隐私保证。除定义方法所必需的内容外，这类主张核对放作者意见，不塞进替换正文。

incremental learning应说明新信息和模型更新，不默认增加新类别：P30面对分布变化更新分类器，P63还处理测量输入维度改变。continual learning进一步关注序列学习中保持早期能力（P64/P65）；历史缓冲只是可选设计。这些标签可以重叠，按实际顺序、反馈和保留能力的问题说明，不强行分成互斥类别。中文基础译名与子类的核查范围见词库，不用某个子类的用例给所有复合名称背书。

## 变量及其特征

| 表达 | 语义边界 |
|---|---|
| variable-wise encoding / features | 按变量分别组织的编码或特征；说明输出对象 |
| independently encoded variable features | 独立编码路径的输出；核对独立性的具体范围 |
| individual-variable features | 较中性的各变量特征描述 |
| variable-specific features | 强调各变量特有的内容，不等于独立编码 |
| variable-specific behavior | 变量之间存在不同表现；有时写清对扰动的不同响应更准确 |
| local variable features | 对某工序、单元、邻域而言的局部特征，不自动等于独立分支输出 |

不能将 specific 全部改成 wise：前者偏内容特有性，后者偏组织或计算方式。当前语料不能为表中每个完整搭配提供直接用例；这些是语义判断，最终仍要服从方法和作者已确认的术语。

显式子集选择中，`feature selection` 保留可识别的输入描述量：P40返回特征索引，P61按排名递归删除过程变量输入；`feature extraction` 则构造描述量。来源名称还需结合其局部定义：P62将输入加权及排序层称为feature-selection layer，该层定义本身没有固定数量子集。介绍该文时保留归属与加权操作，不能把所有注意力权重都升级为选择机制，也不必把加权输入改称新提取的坐标。

说明减少的是哪种对象。保留的频谱或统计描述量仍可能依赖全部原始传感器；如果计算依赖允许，实现也可以只计算所选描述量。特征数量本身不能证明节省了预处理、移除了传感器或加快了推理。先追踪采集及预处理依赖，再按实际测量或计算给出收益。已实现的传感器子集可支持减少模型测量输入的表述，不必另做拆除物理传感器的试验。

## 未来预测目标与寿命量

先明确预测什么、相对于哪个时刻。P45 p.6按完整退化轨迹构造有上限的RUL标签，P81 pp.3,6按其案例使用RUL/TTF目标；P95 pp.3-4预测未来过程变量，再关联运行限值报警。不能因为都叫prognosis就把未来轨迹改称RUL。

| 对象 | 需要说明 | 不能自动推出 |
|---|---|---|
| 未来过程变量轨迹 | 目标量、单位、发出时刻、预测步长和可用输入 | 剩余寿命目标、物理因果模型或已实现报警 |
| 当前健康指标 | 指标构造与评价 | 没有终点映射也能得到失效时间 |
| 剩余寿命 | 当前参照时刻、寿命终点/失效准则、单位及目标定义 | 一个cycle就是一秒，或任意越限都终止使用寿命 |
| 截断/归一化寿命标签 | 上限或尺度，以及评价的参照目标 | 早期真实剩余寿命恒定，或该误差等于未截断寿命误差 |
| 基于预测的报警 | 决策规则、参考事件、真实发出与越限时间 | 轨迹RMSE降低就预警更早 |

运行周期、物理时间、原始传感采样点及模型窗口分别计量，采样频率不决定寿命周期的时长。已知历史失效时刻可以构造监督标签，而不作为预测输入；未知评价结局不能进入声称当前时刻可作出的预测。发出时已知的未来控制计划与后来实现的测量值不同。按[未来量及寿命评价](experiment-evidence-design.md#forecasting-and-life-evaluation)写实际访问和输出，不全面禁止带未来时间下标的量或合法历史目标构造。

## 回归误差与目标尺度

分开物理目标、拟合所得目标变换及实际评分坐标。单目标采用固定非零仿射尺度`y=a*z+b`，参照和预测均一致变换且评分样本/权重相同时，`MAE_y=abs(a)*MAE_z`、`RMSE_y=abs(a)*RMSE_z`。归一化误差按归一化量报告，或还原后写对应物理单位；表头不能给数值自动赋予单位。非线性变换另核真实逆变换及评分路径。

对`R2=1-SSE/SST`，明确评分参照均值、权重和样本范围。非恒定目标在一致的固定仿射变换下R2不变；R2可以为负，不因误以为有界于0到1就裁为0，也不未经核实改成相关系数平方。用真实参照计算评价分母的均值，不等于拿它拟合预测器或预处理。恒定参照的SST为0，软件将非有限量替换为1/0是一种报告约定，不证明原比值已定义或不存在预测误差；先核实现，不将陌生有限值直接判为造假。[官方r2_score说明](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.r2_score.html)只是具体约定，不指定工具包或期刊规则。

MAPE须写分母、零/近零处理及相对值是否乘100显示。普通比例误差在非零乘法缩放下保持，但中心化可改变分母意义并产生零值。保留有合理比率尺度的MAPE，不全面禁止归一化评价，也不代选epsilon、丢弃零目标或换指标。[官方MAPE说明](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.mean_absolute_percentage_error.html)仅举一种相对值/epsilon实现。

多目标保留各目标结果及声明的尺度/权重。原坐标下逐目标等权均值与缩放后误差均值可产生不同排序，回答的问题也不同；不同单位误差的数值合成不自动具有某个目标的物理单位或真实应用成本含义。合理数值综合指标可以保留，须如实命名。

P17 p.5分开浓度误差、趋势判断及容差通过率；P34 p.6给出归一化说明及式(58)-(60)。这些语境不认证源代码、全部逆变换或每种阈值规则。结果按已测目标解释误差或权衡，不由RMSE下降直接推出趋势、通过率或控制收益；计算核查放设置/作者说明，不把摘要写成审计清单。

## 预测输出与区间

先明确不确定性属于什么量：模型参数、潜在特征、条件均值与一个新测得的质量值不是同一对象。参数等对象的后验区间须指明对应的量；输出预测区间针对规定的观测值，不能自动改称均值置信区间。重复训练得分的误差条又是另一种变异来源。

随机前向计算时，区分预测分布所表示的变异与数值估计其矩的误差。增加蒙特卡洛抽样可改善数值近似；将预测标准差除以抽样数的平方根既不构成单个输出的区间，也不自动构成有效的均值区间，均值估计误差须另核方差组成与抽样依赖假设。说明是否计入观测噪声和模型不确定性，不能由潜在方差推定二者均已包含。正态矩近似不等于任意预测分布的精确分位数。

P103 pp.4-6连接预测量与过程监测，P104 pp.5-6连接软测量输出区间与覆盖率/宽度评价；它们不是同一种算法的完整名称准入。写清单变量边际区间或多变量联合区域、目标与发出时刻、单位及使用区间的决策。名义水平与实测覆盖率不同，总体覆盖率不建立每种工况的覆盖保证。仅在论文确有相应输出或可靠性主张时加载[区间评价](experiment-evidence-design.md#output-prediction-intervals)；“预测区间”译法及原文公式的核查范围见词库。

## 来源角色与派生表示

先辨认source指什么：不同工况域/站点的数据集、同一事件同步采集的不同测量流，还是同一父样本派生出的表示。P44 pp.2,4-5是多个运行工况的数据域；P38 pp.4,6-7是视频/电流采集流，二者不是同一种输入结构。几个数据来源不自动证明不同模态或域偏移，也不要求没有事件配对关系的工况数据做时间同步。

## 反事实输入及用途

针对以诊断类别为目标的输入生成，明确原始输入、指定结果、可改坐标、返回候选及判定其目标一致性的模型。还须说明目标是否不同于原预测；保持原预测类别不构成类别改变的解释。P62 pp.5,7返回指定类别的输入以解释模型，P94 pp.4-5调整选定样本以生成目标故障类别的训练数据。两者支持限定的共同操作，不代表同一种架构、预测路径或真实工艺原因识别。

|---|---|---|
| 模型解释 | 改动后的输入与指定模型响应 | 目标一致性、变化/距离及解释范围 |

## 权重作用与类别决策

还须检查损失系数的**计算图**。预测相关因子可产生自己的导数；停止梯度则在本次更新把其当前值视为常数。合成例L=(1-q)^2*(-ln q)，q=1/2时，对q的完整导数为-ln(2)-1/2，停止因子梯度则为-1/2；若q=sigmoid(z)，对z分别为-ln(2)/4-1/8与-1/8。前向系数相同不代表参数更新相同；冻结权重网络的参数也不自动阻断其输入梯度。按真实实现区分类别计数常数、可微置信因子及已停止梯度的前向因子，不强制统一处理或新增推理模块。P96/P100的[系数位置配对](engineering-application-terminology-bank_CN.md#九已核验核心名称与未完成范围)不认证完整损失或源代码的求导实现。

先确定权重乘在哪个对象上、在哪个阶段使用。P92 p.4用权重决定生成增强样本时选取哪些少数类样本；P93 p.5在ELM目标中对训练残差加权；P94 pp.3-4先重加权再选取增强原型。三者作用不同，不是同一种类别加权分类器的匹配定义。P39 p.5的focal因子随预测改变，也不自动是类别频数的倒数。保留各来源自提名称，不一并接受其因果解释或少数类收益主张。

P96 p.3式(3)-(4)明确给交叉熵乘类别因子，其p.6提出的目标还通过间隔改变类别logit，再施加因子，两个操作需分开。P97 p.4表1列出带类别因子的加权交叉熵，p.8式(35)-(36)却显示未按类别加权的二元交叉熵和一个整体分类目标系数。缺少实现依据时保留此冲突，不凭算法表或题名认证完整损失，也不将其充作无歧义的第二篇匹配定义。

独立的P111 p.5式(16)对类别加权负log-softmax项求和，P112接受稿p.4式(2)对分类项按观测数取平均，支持已核查的多分类基础形式。P112明确权重与类别频数成反比，所读P111段未给构造规则，不能由共同名称补入。P112观测单位为像素，不是流程窗口。

复述加权目标时明确归约：`sum(a_i * l_i)`、除以观测数、除以`sum(a_i)`不是同一定义，最后一种须有正分母。将全部固定权重翻倍，前两者翻倍，第三者不变；组合目标还须核相对系数，不能直接断言等价。先给logit乘权再softmax，也不等于对所得负对数概率乘权。满足相应假设时，重采样可以对应加权期望风险，但有限抽样更新及归约约定不因此相同。细节放在目标/设置中，摘要只选与方法作用有关的信息。

在对数内部调整logit与在交叉熵外乘系数不同。P18 p.4式(6)将类别先验偏置用于训练目标，p.5式(10)的调整则用于构造伪标签，不自动是最终诊断预测规则。逐阶段核符号、对象及下一用途；相反符号未必是错误，post-hoc这个名字也不决定它一定在最终预测时使用。若未独立核实译名，可保留logit并解释为归一化前的类别得分，不换成概率或真实物理代价。来源特有的balanced-softmax和间隔名称保留归属。

题设确有类别固定权重时，正面写清按类别确定的因子对哪个训练损失加权。采样概率改变抽到哪些样本，特征权重改变表征，决策分数权重改变预测，加权F1中的支持度权重改变评价平均，不能互相推出。逐样本系数不必在同类内恒定。系数若先乘残差再平方，要核对平方后的系数，不改写成线性损失权重。

特征系数还须核查后续接收运算。P98 p.6式(10)按目标伪标签统计各类样本数，据此先乘目标特征，再送入映射，即`phi(w*f)`；P44 p.5式(13)则将加权特征送入域判别器，均不是P96分类损失外乘系数的第二定义。没有相应齐次性条件时，不能直接把`phi(w*f)`移写为`w*phi(f)`；线性映射及部分满足所需一次齐次条件的非线性映射可等价。所读P98方程未核定具体非线性核，合成二次映射反例不能冒充其实现。其计数表达式也不是字面频数倒数，不因附近文字这样描述就移植为统一规则。保留来源公式与待核实现，不为句子顺口将系数移到另一层。候选类别固定时，这里统计的是伪标签分配，不是新建故障类别。

沿拟合后的预测器核对真实决策，训练损失加权不要求预测时再次给类别分数乘权重；明确实现的分数校正则是另一操作。按[指标及权重核查](experiment-evidence-design.md#8-metric-integrity)确认权重来源和采样对有效目标的影响。按实际类别表现解释权衡，不从balanced这个词推断少数类改善、概率校准或真实误分类代价。

P39-P40 是相邻机械领域的用例，不代表流程工业监督形式统一。P40 的邻域生成标签值属于学习对象；要解释为物理严重程度，还需与损伤、强度或明确严重程度目标建立独立依据。定义合理的论文专用术语不必全局改名，也不能仅凭题目判断全领域用法。

主动学习须沿样本选择、外部标注、学习器更新核对（P89-P91）。获准获取的训练池标注可合法用于学习，保留作最终评价的标签则不能选模型；模型生成目标又是另一监督来源。主动获取标注可与半监督目标结合，但只对无标签池评分并未说明采用何种半监督目标。还需看选择对象：请求标注的样本与区分故障假设的物理激励不是同一动作。预算单位、获取阶段及新类别规则按实际定义，不由active一词推出实时交互。

零样本诊断须分开**实测训练样本、类别语义和合成训练对象**。P05/P06预先提供未见故障描述而无其带标签测量例，P80还生成未见类特征用于分类器训练。生成向量附带的条件类别ID不是新增采集并标注的真实故障样本；已见类历史标签和专家描述仍是监督/资源，不能把zero-shot写成整个学习历史完全无标签。是否用无标签未见类测量进行适应，与这一带标签实测样本边界分别记录。

故障属性项可以指明受影响变量或症状，但不等于该变量的实测值。P06属性层次及P05类别描述承担类别语义作用，不把原始过程变量改称attributes，也不构成生产工序划分。语义匹配可识别预给候选中的具体未见故障，unknown拒识则只标出已知集合外样本；先明确候选类集合，以及描述的构建/调整所用信息，再借用任务名。LLM提示中没有示例，是另一种资源陈述，不能自动等同某故障类没有带标签训练测量。

## 结构与操作

- intra-stage 是工序内，inter-stage 是工序间，cross-stage 是跨工序。`inter-stage relationships` 与 `cross-stage fusion` 可以在一个摘要中并存，不必强制统一所有前缀，更不能颠倒 intra/inter。
- stage-wise 表示逐工序处理，stage-level 表示粒度，stage-structured 表示保留了已定义的工序结构，三者不互换。
- partition 可来自固定工艺划分；grouping 可预设或学习；clustering 需要实际聚类机制；软分组不一定输出硬簇。
- aggregation 对集合汇总；fusion 结合信息来源；interaction 建模相互作用。需对照操作选择，不靠“高级词”替换。
- relationship 范围较宽；dependency 不自动表示因果；correlation 需要相应统计量或合理定义。
- topology、prior、constraint 分别核查工程来源和数学作用；加性注意力偏置不是硬约束，也不自动是因果图。
- causal convolution 表示特定输出不读取未来输入；预测依赖表示信息对预测有用。二者本身均不识别物理干预效应或根因，不能只因出现 causal 就混同。
- spatial / spatiotemporal 应定义所指轴或关系：物理位置、工艺拓扑、图邻域或明确建模的变量间结构；时空表述还需说明时间轴。模型网格相邻不自动等于物理接近或工艺耦合。
- gate 调节贡献，attention 计算关系或加权聚合，fusion module 结合路径。核查形状与操作，不混淆分支和融合模块。
- residual connection、信号分解后的剩余分量和测量减预测值的误差是不同对象，先定义运算对象及后续用途。匹配维度的线性路径可以构成残差连接；独立路径拼接不自动成为加性连接。
- generator、discriminator、故障分类器须按真实输入、输出和训练目标区分：generator可能合成样本，也可能编码已采测量；discriminator可能辨别实测/生成身份，也可能辨别域身份，两者都不自动是物理故障类别。保留来源名称归属，同时写清实际作用（P70-P72）。
- unified / global / plant-wide 需说明表示范围，融合两条路径不证明普适泛化或完整全厂覆盖。

stage 先区分生产单元、一个批次中的时间阶段与学习阶段；local/global 先确认局部性的定义域，时间感受野不等于全厂区域；propagation 区分图上特征更新与真实扰动的传播。这些选择会改变科学含义，不只是风格问题。

多头注意力先分清头轴、被关注的位置轴及特征轴。P11拼接头特征后作输出投影；P82还将系数矩阵送往另一个汇总。说明合并的对象及其使用者。同一输入的不同Q/K/V投影仍可属于自注意力，查询改由另一输入提供改变的是来源关系，不是头数。注意力行归一化不使投影后的输出成为故障概率，也不证明独立物理关系。参见[已核多头范围](engineering-application-terminology-bank_CN.md#九已核验核心名称与未完成范围)，不从基础attention名称直接准入任意完整变体。

因果卷积须核对抽头偏移、填充及时间轴（P81/P82）。可访问当前位置，严格只用更早输入的预测则须有相应输入/目标滞后；dilation是在模型网格上拉开抽头，不是改变采样频率。声称逐点因果输出前，沿后续运算追踪信息范围，使用[决策时刻核查](experiment-evidence-design.md#3-split-integrity-checklist)。完整历史窗口可合法用于端点估计，不因内部位置访问该可用窗口内的较晚位置便认定泄漏端点未来；保留真实任务及[基础名称范围](engineering-application-terminology-bank_CN.md#九已核验核心名称与未完成范围)，不补出物理因果或未核完整模块的保证。

图模型说明应分清节点更新、后续单元/图级汇总和最终决策。P13先结合邻居与节点自身特征，再单独形成单元表征；P14先作邻接加权投影，再融合特征并分类。对更新节点取均值不自动使各节点表征相同，但汇总值未必保留各节点的独立数值。发送/接收方向按实际矩阵乘法核对，不能凭A_ij或借来的箭头图判断；在固定允许连接内学习权重，不等于整个拓扑均由数据学习。使用[消息传递基础记录](engineering-application-terminology-bank_CN.md#九已核验核心名称与未完成范围)，不顺带引入来源完整的因果或层级模块名。

加性残差路径须核对特征轴及投影、激活、归一化位置（P11/P15/P14）。投影输入不等于恒等映射，但相加仍可属于残差学习；相加不自动证明无损保留，去趋势后的剩余分量也不自动是故障分数。保留作者批准的自提名称并说明实际汇合操作，不能因名字带residual就把拼接改成相加，或将完整名称准入通用库。参见[基础词条](engineering-application-terminology-bank_CN.md#九已核验核心名称与未完成范围)。

门控先明确输入、系数轴、被调节对象及后续结合。P08门控卷积特征，P33门控注意力输出，P36加权专家用于质量预测，不要求所有门采用同一种归一化或离散选择。P19的`F+w*F`系数为`1+w`，小sigmoid权重衰减的是附加分支，不必然使最终输出低于原F；后续投影或归一化另行核对。注意力和门控描述可以交叠，保留来源名称并说明实际运算。门值范围本身不建立故障概率或传感器删除含义；参数固定而系数随输入变化也不等于在线参数学习，省算须有真实执行路径而非仅凭小权重。

软阈值化采用非负阈值时，先明确处理哪个量（P87 p.3式(4)、P88 p.3式(2)）：阈值区间内置零，区间外保持符号并减小幅值。作用于特征值不等于剪掉网络参数，固定训练权重逐输入计算不同阈值也不是在线学习。继续核对旁路与融合，某支为零不保证最终表征为零。小幅值不直接识别噪声；正文正面说明收缩操作，去噪结果则需相应证据。P88印刷sigmoid式在零处分母为零，与所述有界范围矛盾，不静默修正后照搬；基础定义不认证完整模块或实现。

原因分析还要分清起始扰动、最早测得的响应和模型选中的节点。学习的有向图、图上载荷重新分配得分与真实产线操作变化不是同一对象（P13/P16）。因果目标及识别假设明确时，保留依据观测数据成立的条件性效应估计，不要求每个因果句都先有实体干预试验；反之，预测关系或模拟图攻击本身也不识别物理效应。涉及相应主张时使用[解释证据检查](experiment-evidence-design.md#7-interpretation-design)，不把根因分析强加给普通故障分类论文。

multiscale convolution先说明不同分支或层改变了什么，以及作用于输入的哪一轴。卷积核范围、扩张率、步长和前序层共同影响输入支持范围，核宽不等于整个网络感受野，更不等于已测物理时间常数。P01/P11/P15的基础用例均采用不同分支支持范围，但输出可以相加或拼接，完整自提模块名仍归属来源。合理的模型local/global描述不必上升为物理尺度，频带分离或全厂范围则须另有依据。摘要、贡献应衔接组合特征的真实后续用途，不额外补出物理收益。

aggregation可结合或汇总一个明确集合，不必然降维；fusion须交代信息来源与结合层级；interaction须交代关系计算或交互对象，不自动证明物理影响。它们有交叠，不能只按词名认定唯一算子。P01 pp.4-5结合工序表征，P03 pp.4-5加权结合注意力输出，P14 p.4拼接多尺度特征后分类：相加与拼接都可实现特征融合，但不能因此补出注意力、门控或学习对齐。分类器预测值的组合与其隐特征的组合层级不同，即使都用加权和。摘要写真实输出及后续用途，贡献写实际推进点，不把更复杂的融合名称当成创新。

不强行建立aggregation与fusion互斥的分类：P02 p.5第3.3.2节式(31)把池化特征加权结合称为aggregation，P03式(17)把另两种表征的相关组合称为fusion；完整模块名称仍不能互换或直接视为多源通用类别。P02同页文字称某输入为max pooling，但式(28)定义为平均，借用实现细节时保留这一待核实差异，不擅自挑选其一。借鉴术语用例不等于认可来源完整算法。

mask、sparse、constraint 需核查作用位置：注意力边为零、logit 置零、类别被排除、专家不执行是不同结果。有限 logit 置零后仍可获得正的 softmax 概率；普通稠密 softmax 也不证明稀疏执行。同理，块对角图限制的是该次图运算，不一定限制后续特征混合，更不证明物理单元独立。摘要中的作用应落在完整计算实际支持的层面。

压缩或选择主张须沿张量尺寸和保留的执行图核查。P74减少查询集合，改变注意力分数计算，但输出仍含其他channel值token，重要性加权不证明表征集合变小。零权重仍可能按稠密方式存储/执行，真正删除channel则可减少后续张量维度；二者都不自动证明实体传感器需求或实测耗时降低。另一来源只做加权，不是禁用真实删除操作的理由。

固定参数掩码将选定标量权重置零，即使张量形状不变，也可准确描述为unstructured weight pruning。非零权重数、分配的参数位置、序列化字节数和实际执行的运算分别核查，名称本身不证明资源收益。把所有权重限制到指定区间则改变取值范围，不是选择保留子集；P76的背景名称与原始WGAN这一步冲突，其自身输入梯度惩罚又是另一计算。保留来源归属，按实际计算表述；完整名称进入通用推荐前仍遵守[准入核查](engineering-application-terminology-bank_CN.md#零专业名称准入与译名核查)。

还须记录修改对象的**使用阶段**：带掩码的编码器副本可提供训练视图，而原编码器用于预测；这种关系可以有价值，不因此使部署模型更小。参数掩码、缺失测量掩码、图边删除和channel删除不是同一对象。摘要、贡献及总览保留实际训练与预测路径的关系，不为它临时起一个新模块名。

剪枝变体若在评价前已生成并重训，应与运行时选择现有变体或转移任务的策略分开（P85 p.4）。按输入状态选择模型不一定更新预测器权重。明确准确率约束使用什么量：候选模型估计的总体准确率不是每次预测已经实现的正确性。计算成本关系可支持在该假设下的模拟结果，不直接证明设备耗时。连清被选模型与真实故障决策，并在结果句保留评价层级。

分支精确转换也取决于运算而非同名。P45 p.5描述兼容卷积/归一化分支在共同激活前合并，固定推理统计量下归一化可为仿射变换，随输入batch变化的归一化则不同。先合并仿射量再激活，通常不等于先逐头激活再平均。声称等价前核对padding、尺寸、bias、统计量和激活位置；完整来源转换仍保留归属，不认证所有原公式或通用模块家族。

池化须说明归约哪一轴、保留哪些轴，以及输出交给哪一步。P01 p.4先汇总单个工序的编码特征，再由后续操作融合工序：单个输入中的global pooling不等于建模全流程关系。均值、最大值和协方差池化是不同计算，不能作为润色同义词互换（P02 p.4使用协方差池化）。均值/最大值归约对已编码位置的对称性，也不证明整个模型不受原始输入顺序影响；前面的编码器可能已编码顺序。写清汇总对象和后续用途，不自动推导去噪或诊断改善。

核对平均的集合与分母：单元大小不同时，单元均值的等权平均不等于所有节点一起平均。若实际定义采用掩码均值，只排除明确规定的填充或未观测位置，真实测得的零仍是有效值。P13式(9)先对节点特征平均，再作投影和激活；读出可学习，但式中的平均系数均匀，不能因后续投影就补出非均匀节点权重。使用[已核池化记录](engineering-application-terminology-bank_CN.md#九已核验核心名称与未完成范围)，不因汇总特征后接门控或预测器就另造通用模块名。

软分配须明确被分配对象、候选组/中心、归一化轴与后续用途。P33/P48定义样本到聚类的权重，不是变量到组的权重。归一化分配向量、随后argmax得到的硬标签、仅用于加权求和的注意力向量仍是不同对象。保留确实实现的软分配，但不能仅从归一化推导物理工况、模糊隶属度或已校准不确定性。摘要把被分配的表征与真实后续操作连起来；除消除歧义所需外，索引细节留在方法中。

## 分方向加载

**软测量**先说明被估计的量与当时可用于估计它的测量。P57的primary/secondary表示目标/输入角色，不是重要性排序或第一/第二个实体传感器。目标量的历史观测可在已发布时作为输入；工艺时间早于当前，并不保证延迟化验已经获得。润色前区分训练目标、历史目标输入、当前估计与未来目标。普通统计意义的predict可以保留；预测未来的forecasting主张另须说明目标时刻相对估计发出时刻的关系。采用[限定基础名称记录](engineering-application-terminology-bank_CN.md#九已核验核心名称与未完成范围)，不为每个英文sensor名称新造直译。

- **多速率观测：** 分开流与流之间的差别及单路内部间隔变化。各路固定周期不同，可以同时存在时间戳不重合；不因时间点错位就认定单路间隔不规则。多速率、非规则时间及缺失也可并存。asynchronous应按实际采集或控制语境定义，不强定跨领域唯一含义。P08/P73定义速率组及已观测子集，P24建模不等样本间隔；它们是相关观测设置，不是可互换的完整模块家族。

相关概念见[采样与时间概念速查](#采样与时间概念速查)，按对象和单位连接常用词，不把一个问题名称当成完整术语表。

仅校准问题用词时，先用[观测可用性与计数概况](problem-first-classification_CN.md#观测可用性与计数)，不先选方法。网格空白、预期采集丢失和已有值晚发布，可能需要不同描述及统计分母。

- **有限监督：** few-shot 说明有标签样本数；zero-shot 说明未见类别与可用语义；semi-supervised 区分有无标签数据；weak supervision 可能是包级或粗标签；self-supervision 解释目标生成。参考 P05-P06、P17-P22。
- **模糊：** 隶属度不自动等于校准概率；定义实际的隶属函数与聚合，模糊聚类层不一定具有语言规则。证据不确定性也不是同一对象。参考 P07、P27-P29、P33。
- **知识引导：** 区分专家规则、拓扑、物理定律与学习相似性，来源与进入模型的方式比形容词重要。参考 P04、P12-P14。
- **质量相关诊断：** 先明确目标是产品检验类别、定量质量测量，还是过程故障是否影响质量的判断。缺陷分类不自动识别责任单元或原因；方法没有质量相关/无关分解时不强行添加，已有这种决策时也不能省略。参考 P01、P09、P16 及[任务区别](topic-playbooks.md#10-interpretability-localization-root-cause-and-trust)。不在摘要和实验总览中反复罗列非核心缺陷名称。

修改题目或Gap的工况变化用语前，按[问题层概况](problem-first-classification_CN.md#工况变化与跨工况问题)分开新工况、时间变化与新故障类。读清两个条件方向及保持量；仅类别比例改变，不证明满足类条件分布固定的label-shift设置。

| 分方向术语 | 必须保留的含义 | 修改前核查 |
|---|---|---|
| conditional drift / concept drift | 某个明确分布的变化，不是统一的漂移定义 | `P(X)`、`P(Y)`、`P(X|Y)`、`P(Y|X)` 哪个改变、哪个保持？P30 使用特定的类条件分布定义。 |
| event-triggered learning / sampling / alarm | 分别是学习更新、采集事件或诊断输出 | 什么触发什么，所需测量或标签当时是否可用？P27 讨论学习更新。 |
| generation condition / operating condition | 生成条件可为故障类别或健康指标，运行工况则描述运行条件 | 先看条件变量，不把所有 conditional generation 都改写为工况条件生成。参考 P32。 |
| diffusion step / acquisition time | 模型加噪去噪迭代与实际测量时间 | 不默认扩散步代表物理时间演化，也不默认去除实际传感器噪声。参考 P32、P35。 |

| filtering / smoothing | 使用目标时刻及之前观测估计状态，与同时使用更晚观测估计状态 | 明确被估计时刻及信息截止时间。训练平滑、延迟回顾估计与当前时刻预测用途不同；P34 区分参数拟合和在线估计。 |
| efficiency / real time | 某种资源比较与满足决策时限 | 区分训练、生成、预测成本及计时范围；参数少不证明时延低。 |
| task balancing / load balancing | 任务训练影响与工作负载/专家使用的分配 | P36 平衡任务梯度，不因此证明稀疏路由或设备负载平衡。 |
| cross-modal alignment / synchronization | 学习的表征兼容性与采集时刻的配对 | P38 区分同步采集、token 构造与跨模态注意力；特征维度相等不证明时间已配对。 |
| local outside-class / unknown fault | 子分类器标签集之外与整个系统未知 | P37 的成对子分类器 OOD 类本身不构成系统级新故障检测。 |

### 采样与时间概念速查

只查当前句子需要的行。这些是量的区分，不是新机制名称，也不要求摘要列出所有时钟。先明确采集对象，再介绍模型如何表示它。

| 英文词或描述 | 对象、单位与中文表达 | 写作决策 |
|---|---|---|
| sampling period; nominal sampling period | 采样周期；相邻采集的固定或计划间隔，单位为秒等时间量；nominal说明计划值 | 区分计划与实测间隔。丢失一次计划采集可使观测间隙变长，不代表名义周期改变。 |
| sampling interval; time interval between observations | 采样间隔或观测间的时间差，单位为时间 | 明确两个端点。相邻间隔`t_i - t_(i-1)`不同于P24 p.4式(10)的所有样本对时间差`abs(t_i - t_j)`；间隔矩阵未必是距前一样本的间隙向量。 |
| sampling frequency / sampling rate | 采样频率／采样率；所指测量流单位时间内的采集次数 | 均匀采样时`f = 1 / Delta t`，周期更长对应频率更低。采集频率、过程测量中的振荡频率、重采样后模型输入的速率分别表述。 |
| rate-group index; interval multiplier | 速率组编号或明确定义的间隔倍数，均无量纲 | 不能直接当作Hz。先读定义再判断编号越大是否越快；参照周期固定时，周期倍数越大，采集越慢。 |
| reference time grid; grid spacing | 用于组织模型输入的参考时间网格及其间距 | 说明位置是实际采集、保持、插值还是未观测。公共网格不意味着传感器共用一个采集时钟；保持值不新增采集。 |
| window length; window stride; output interval | 窗口长度、窗口步长、预测输出间隔，分别指输入范围、相邻窗口位移与发出预测的时间间隔 | 说明长度／步长以原生观测数、网格位置数还是物理时间计。不规则观测的点数本身未必确定时长；输出间隔未必等于传感器采集间隔。 |

不规则观测可以定义平均速率统计，但不能由此推出等间隔。平均间隔的倒数通常不等于间隔倒数的平均；报告数值速率时说明采用哪种统计及观测范围。

序列位置、距最近测量的时间、化验结果发布延迟与实体过程时滞的端点或作用不同，即使部分都以秒计也不能互换。写实际时间输入及接收对象，不临时造时间限定的门控或模块名。可用性与缺失计数继续按[观测概况](problem-first-classification_CN.md#观测可用性与计数)核查。

P34 pp.4-5与P73 p.3定义速率组和可获得测量；P23 p.2明确说明单路均匀完整，而共同网格显示存在未采集位置。P24 pp.3-4则定义不规则观测及样本对时间差。迁移表达时保留这些区别。[中文用词核验](engineering-application-terminology-bank_CN.md#九已核验核心名称与未完成范围)支持周期／间隔／频率的基础词形，不认证本表所有描述性组合为固定专名。

### 对齐：明确对象和判据

alignment 应对应实际受约束的对象，不能作为融合或信息已恢复的同义词。

| 实际操作 | 描述依据 | 不能直接推出 |
|---|---|---|
| 采集/时间对应 | 时间戳、触发、时延或事件匹配规则 | 张量等长或嵌入等宽本身不证明物理事件配对 |
| 维度兼容 | 将表示映射或变形为指定长度/宽度 | 不必插值测量或估计缺失值；P08 p.6将编码序列映射至共同长度 |
| 分布对齐 | 对明确特征总体定义统计或对抗目标，如P10/P44 | 边缘分布目标本身不建立逐样本对应或保证类别语义；类别条件目标须明确真实标签或伪标签来源 |
| 配对/表征一致性 | 对配对或对比表征定义具体关系，如P08 | 有一致性学习目标不证明物理同步、因果性或完整信息保留 |

使用MMD时，应说明比较哪两个分布，以及它是训练目标还是评价统计量。匹配两个边缘分布不等于测量依赖联合分布的互信息；有些依赖性判据比较联合分布与乘积分布，因此应核对对象，不能一概否定所有联系。固定对象上的核差异下降只支持该项观察，不自动证明共享诊断信息增加。摘要保留实际操作与任务用途，未支持的解释和所需证据放在作者说明中，不把替换句写成一串防御性限定。

## 模糊规则的不同输出量

对采用归一化规则激活来加权局部输出的预测器，沿实际量串联：`输入表征 -> 隶属度 -> 规则激活 -> 归一化规则权重 -> 局部输出组合 -> 任务输出`，不把整段计算都叫membership。P27式(4)-(6)用于质量回归；P77式(3)-(7)先组合局部类别分数，再沿类别轴softmax。输入匹配、乘积激活、规则权重、局部后件和最终类别概率是不同对象。除非定义了相应划分约束，隶属值不必加和为1；跨规则归一化不使规则变成故障类别。先组合分数再softmax通常不同于先softmax再组合概率。保留真实顺序和合法的类别概率输出，不由归一化推断经验校准。其他模糊推理系统须按各自定义核查输出及聚合，本链条不是所有模糊模型的必选架构。

分别命名局部后件与组合运算。常数后件与关于输入的含常数项线性函数不同；权重随输入变化时，两类完整映射都可能非线性。固定前件函数时，组合数值分数可以关于后件系数线性，却不关于输入线性。联合拟合前后件及后续softmax须看实际目标；P77/P108的一阶TSK限定记录不把所有高斯加权模型说成同一分类器，也不使数值规则自动成为专家指定的实体工况。

明确规则的输入定义域。潜在坐标可以服务数值模糊预测，但不自动具有“温度高”等已验证物理含义；使用实体输入并有语言规则依据的研究仍可作对应解释，不能因另一模型使用embedding就一概否定。说明规则来自专家、数据拟合还是两者；中心、宽度和后件系数可以学习，输入条件化预测不因此变成在线训练。

摘要把匹配及规则输出接到真实质量估计或诊断决策。若训练一致性损失作用于规则激活，就说明这个接收对象，不虚构另一个预测时融合模块。具体量的核对放作者说明；参见[基础名称与译法记录](engineering-application-terminology-bank_CN.md#九已核验核心名称与未完成范围)。

## 证据分类中的不同输出量

P52/P75所核查的非负证据、单位先验形式中，按实际定义区分：`alpha_k = e_k + 1`、`S = sum_k alpha_k`、`b_k = e_k/S`、`u = K/S`及期望类别概率 `p_k = alpha_k/S = b_k + u/K`。belief mass之和为`1-u`，类别概率之和为1；S包含先验贡献K，不只是网络证据之和，更不是实测样本数。其他先验或证据回归模型须看各自定义，不能将此形式强加给所有带evidential名称的方法。

随输入变化的Dirichlet输出不自动是序贯贝叶斯更新或在线参数学习。相同期望类别概率可对应不同集中程度和不确定性质量；先缩放证据再加先验，不等于直接缩放alpha，解释强度变化前须核对运算对象。因此更小u本身不表示更低错误概率、样本一定属于已知类或诊断可靠性按比例提高。反过来，期望类别概率仍是合法模型输出，不能因为同时有belief mass和u就禁用概率措辞；区别重要时，明确confidence指哪个量。

分别连到实际使用者：类别决策可使用p，拒绝规则可使用u；原方法没有拒绝决策时不补造。网络输出的证据不是物理证言或任意特征权重，该输出头本身也不是Dempster合成规则。完整来源名称保留归属，[基础名称记录](engineering-application-terminology-bank_CN.md#九已核验核心名称与未完成范围)只支持所述分类形式。语义核查通常放作者说明中，只有定义方法所需部分进入正文。

针对已定义校准分箱的结果，报告该分箱的经验频率与置信度差值。将范围融入结果本身，例如：Confidence agrees with observed accuracy in this bin, whereas the comparison model has a larger confidence-accuracy gap. 若正文已不保留全人群主张，拒绝该保证的理由放作者说明，不再用一个否定尾句重复。若负面发现或必要限制会改变结果含义，则应保留，不是一概删除限定。

## 信念质量的合成与决策

实际实现Dempster规则时，明确共同识别框架及其各子集的质量。对非空A，归一化规则为`m(A)=sum_{B intersect C=A} m1(B)m2(C)/(1-K)`，其中`K=sum_{B intersect C=empty} m1(B)m2(C)`、`m(empty)=0`。要求`K<1`；`K=1`时该归一化表达式无定义。方法可以明确规定弃权或其他替代规则，但不能润色时悄悄在分母加epsilon。数值容差及后备处理在方法中说明，不一并挤入摘要。[基础定义记录](engineering-application-terminology-bank_CN.md#九已核验核心名称与未完成范围)不等于来源完整改进设计的准入。

按对象区分：softmax加权求和合并特征向量，类别证据头构造质量，合成规则组合质量函数。若实现了源折扣且`0<=r<=1`，可将非全集质量乘r，并向全集分配`1-r+r*m(Theta)`，不能直接把剩余单类质量重新归一化来冒充。交代全集质量是否代表未分配支持，全集Theta与空集不是同一对象。不同头或传感器不直接证明证据独立，基于一致性或学习得到的权重也不自动是校准可靠性。

把组合质量连到实际任务决策：若采用概率转换，给出真实定义，集合上的质量不已经是某个类别的概率。不擅自改成类别归一化、不丢弃全集质量，也不给没有拒识的分类器添加拒识。摘要正向串联来源输出、有区别性的组合原则及最终决策，无须罗列全部公式；依赖性与校准的待核查事项放作者说明，除非会改变正文保留主张的解释。基础公式正确不等于新贡献。

## 评价与边界

real-world 表示来源，不表示在线运行。不要习惯性加 offline；若回顾性与前瞻性评价区别影响结论，则应保留。类别不平衡通常在数据和指标分析中展开；只有它确实是研究问题或贡献时，才需要出现在摘要或贡献中。

offline assay 可以准确表示实验室检测或迟到的质量标签，不等于给所有工业数据加 offline 前缀。online 可以指顺序计算，也可以指现场在线评价，必须说清；deployment 需要运行接入，影子评价不能证明闭环收益。

任务名称也需看定义。detection 可能指报警，diagnosis 可能识别类别、位置或原因；文献用法有差异（P02），先看目标与评价再改名。quality prediction 可能输出连续量，也可能预测质量类别（P09），不能为了表面统一把类别标签改成连续质量变量。

连续监测中，window-level、pointwise、point-adjusted、event-level 对应不同评价对象或计分规则。阳性窗口不定位窗口内的异常时刻；命中一次后填满真实异常区间只改变评分，不改变实际报警时间，P07 与 P22 的选择不同。inference time 描述明确范围内的计算耗时；detection delay 需要对齐真实报警、参考起点以及所需信息的可用时刻。early warning 还需要定义提前预警目标，计算快不能代替这些时序证据。按需阅读[连续监测评价](experiment-evidence-design.md#continuous-monitoring-what-is-scored-and-when)。

普通实验章节可以用 experimental settings；若确实定义了可复现的评价程序，evaluation protocol 也不是错误。作者不喜欢某词，不应上升为整个领域禁令。

真正不可接受的是虚构结果和引用、编造输入语义、无依据的因果/部署/泛化结论及隐瞒选择泄漏。没有哪个普通单词本身足以证明这些问题。
