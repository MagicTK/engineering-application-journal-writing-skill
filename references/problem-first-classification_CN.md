# 工业问题优先分类

[English](problem-first-classification.md)

用于整理工业问题、数据与标注限制，或为后续文献路由准备分类。它补充[五轴体系](industrial-ai-taxonomy.md)，不是新模型目录。**仅整理问题（problem-only）**时，不强行选择方法、实验或论文范式；任务尚未明确也应保留未知。

## 一、从现实困难出发

文件夹名是检索线索，不是科学定义。结合论文的问题陈述辨清研究对象、现实困难与决策输出；允许交叉标签，不强行整理成一棵树，也不修改作者的文献目录。目录中存在某类文献不等于已精读或核定该方向。

| 检索线索 | 首先所属层级 | 需要从论文还原的问题 |
|---|---|---|
| 数据缺失、多速率、不规则采样 | 观测限制 | 哪个量在何时不可用、形成原因是什么 |
| 小样本、弱监督、标签受限 | 支持样本或标注限制 | 标签数量、标签粒度、标签可靠性、类别覆盖与分阶段访问条件 |
| 多工况、非平稳、未见工况 | 运行或分布条件 | 离散工况、持续变化，还是开发到使用时的分布差异 |
| 复合故障 | 多故障同时存在的设置 | 组合覆盖、标注方式及最终输出；不预设多标签损失 |
| 全流程、多工序、多块 | 对象/尺度及可能的结构 | 具体哪些耦合、传播或异质关系妨碍判断 |
| 多源、多模态 | 输入来源/异质性 | 区分运行域、实际采集流、模态和变换视图 |
| 异常定位、根因分析 | 任务/输出 | 要定位什么或解释什么、什么证据能支持 |
| Attention、Graph、Diffusion、Fuzzy、MoE、LLM、慢特征分析、迁移学习 | 候选技术家族 | 从应用段落提取实际问题，不给方法绑定唯一问题 |
| 轻量化/高效模型 | 技术目标或响应 | 边缘端算力、内存、推理时限或实际硬件限制 |
| XAI/可解释性 | 方法/评价主题，也可能来自决策需求 | 谁需要理解哪个判断，用于什么操作或审计 |
| 期刊目录、Review/综述 | 发表来源/文献类型 | 只作检索筛选，不当作问题或方法 |

复合故障可能采用多标签学习，也可能按组合类别或其他明确输出建模；两者不是定义上的等号。MoE也不限于大模型，具体专家和路由设计仍须核对来源。上述分类用于后续建立多对多的“问题—候选响应—证据”关系，不在当前阶段推荐时序顶会idea。

## 二、问题用词与边界

以下是条件性描述，不是新增通用模块名。按实际研究选用；外部依据及既有准入范围见[文献索引](published-evidence.md)和[术语库](engineering-application-terminology-bank_CN.md)。

| 现实困难 | 候选英文 | 必须说清的区别 |
|---|---|---|
| 观测不完整 | missing measurements / missing values / incomplete process data | 变量/时间覆盖及形成原因；自然缺失与人为遮蔽评价目标不同 |
| 不同采样速率 | multi-rate sampling / multi-rate process measurements | 各变量或组具有不同采样时钟，不等于各自间隔不规则 |
| 不等时间间隔 | irregularly sampled measurements | 时间间隔变化，不只是存在多个固定频率 |
| 时间不一致或晚到 | asynchronous measurements / reporting delay / delayed quality measurements | 分开采集时刻、报告可用时刻、对齐与物理过程滞后 |
| 标签稀缺或实测目标稀少 | limited labeled data / label scarcity / sparsely labeled process data | 标注单位、目标、数量；有大量无标签测量时不能笼统说所有数据都少 |
| 粗粒度或不确定标注 | coarse-grained labels / label ambiguity / noisy labels or targets | 标签粒度与可靠性分别描述；候选备选标签不等于多个真实故障共存 |
| 类别支持不均 | class imbalance；确认长尾时用 long-tailed class distribution | 类别数量与受影响类别，不等于小样本，也不是默认卖点 |
| 运行/分布变化 | multiple operating modes / nonstationary operation / distribution shift | 分清离散与连续变化、开发与使用边界；输入变化本身不证明输入到目标关系的concept drift |
| 过程耦合 | process coupling / interacting production stages / cross-stage dependencies | 已知物理关系与学习关系不同；全流程对象本身不证明耦合困难 |
| 信息来源差异 | heterogeneous process data / heterogeneous sensing / cross-domain distribution differences | 先说明域、采集流、模态、变换视图的实际角色 |
| 多故障共存 | compound faults / simultaneous faults | 故障成员、组合覆盖和输出，不预设具体算法 |
| 执行资源受限 | limited computational resources / memory constraints / inference-time requirements | 实际设备、资源或时限；少参数不等于实测运行高效 |

题目或引言可按实际限制写quality prediction with limited labeled data，或fault detection from coarse-grained segment labels。这些是表达方式，不是强制题目、已有模块名或创新认证。标注成本、安全限制等原因必须有事实依据，不能代写。核心限制在动机处展开，普通数据属性放在数据/分析部分。

## 三、监督信息与训练信号分开描述

先问任务标签有什么，再问训练目标怎样构造；下列类别可以组合，**不互斥**，不是完整系统的唯一标签。

| 术语 | 应说明什么 | 不能由名称推出什么 |
|---|---|---|
| supervised learning / 有监督学习 | 用于拟合的任务目标、单位与来源；可以是类别，也可以是连续质量值 | 标签足够多且正确、没有辅助目标或能识别未见类 |
| semi-supervised / semisupervised learning / 半监督学习 | 有任务标签与无任务标签样本实际共同参与学习，说明针对哪个输出及使用阶段 | 仅存放未使用无标签数据就足够；必须伪标签或独立预训练 |
| weakly supervised learning / 弱监督学习 | 不完整、粗粒度、歧义或不准确中的具体限制，以及采用的定义 | 固定标签比例、完全没有监督或永远排除半监督 |
| unsupervised learning / 无监督学习 | 哪个拟合阶段不用外部任务目标；选择、阈值、簇解释及评价如何用标签另列 | 整个过程没有人工知识、簇编号就是故障名称 |
| self-supervised learning / 自监督学习 | 从数据/变换构造的目标、实际损失、联合/分阶段训练及保留预测路径 | 是弱监督/无监督的总称、必须对比学习或全流程无标注 |

[周志华基础综述](https://doi.org/10.1093/nsr/nwx106)的广义弱监督分类包括不完整监督，半监督位于其中；其他社群常较窄地用弱监督指粗粒度或不可靠标注。因此以实际标注条件为准，不建立唯一强制分类树。

工业实质语境：P17 p.2第二节定义稀疏连续化验目标；P21 p.3第三节A把有标签分类与自构造时序目标联合训练；P26 p.3第三节把采样变换预测与有标签分类结合。P22 p.3第三节A明确窗级标注与时刻级输出不同，即使每窗有标签也不等于每时刻有标签。P19 p.6第三节D的聚类目标不用任务标签，但不据此认证调参、簇解释也未用标签。P20 p.3说明人工数据标注，pp.4,6说明自监督训练角色，不把局部训练目标推广为开发/评价全程没有标签。以上是定点阅读，不是全实现或结果审计。

正常数据建模应记录正常性如何确定、拟合使用什么目标、阈值如何设定。保留来源约定的unsupervised detection名称，同时说明影响主张的筛选/选择信息，不凭重构损失判断全系统监督性质，也不统一改名所有正常数据检测研究。

## 四、小型标注概况

只填写本任务已知字段，不为局部写作生成无关清单：

```text
目标/输出及标注单位：
标签数量与覆盖（类别、工况、时段、场地）：
标签粒度（时刻、窗、事件、产品、批次等）：
标签可靠性和目标来源：
可用且实际使用的无任务标签测量：
已明确的自构造训练信号、联合或分阶段安排：
拟合、模型选择、适应及最终评价的数据/标签访问：
影响术语判断的未知事实：
```

不设置few-shot/半监督的统一样本数或标签比例。目标域无标签、具有语义说明的未见故障类无实测训练标签、整个开发过程无标签不是一件事；不能都称zero-shot。同批次的相关窗口和合成视图不增加独立实测标注批次数。

## 五、仅整理问题的交付

输出现实困难、条件性中英文用词、已知任务/尺度、观测及标注概况和少量待核事实。方法未选则写“Method: not selected”，证据未给则写“Evidence: not supplied”。不选择论文范式、不推荐网络或唯一算法、不设计新实验、不启动idea工作流。后续获得要求后再补候选方法与对应证据，不把目录共现当成唯一解决关系。

## 译名依据与阅读边界

英文设置复用P17/P19/P20/P21/P22/P26，不增加工业论文ID，不认证完整模块名。NSR综述引言/不完整监督节只用于分类边界，不证明流程工业使用普及率。另读[自动化学报半监督原始双语摘要](https://www.aas.net.cn/cn/article/doi/10.3724/SP.J.1004.2013.01871)、[对比学习综述原始双语摘要/关键词](https://www.aas.net.cn/cn/article/doi/10.16383/j.aas.c220421)，核定半监督学习、自监督学习及与对比学习的区别；[中国图象图形学报原始摘要](https://www.cjig.cn/zh/article/doi/10.11834/jig.220854/)核弱监督及粗粒度标注语境，不充作第二篇工业机制定义。另求的自动化学报无监督词条页未能加载，不记已核，也不因访问失败否定既有用语。此导航不新增复合中文模块名。
