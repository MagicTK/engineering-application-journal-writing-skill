# 工业问题优先分类

[English](problem-first-classification.md)

用于整理工业问题、数据与标注限制，或为后续文献路由准备分类。它补充[五轴体系](industrial-ai-taxonomy.md)，不是新模型目录。**仅整理问题（problem-only）**时，不强行选择方法、实验或论文范式；任务尚未明确也应保留未知。

## 一、从现实困难出发

文件夹名是检索线索，不是科学定义。结合论文的问题陈述辨清研究对象、现实困难与决策输出；允许交叉标签，不强行整理成一棵树，也不修改作者的文献目录。目录中存在某类文献不等于已精读或核定该方向。

| 检索线索 | 首先所属层级 | 需要从论文还原的问题 |
|---|---|---|
| 数据缺失、多速率、不规则采样 | 观测限制 | 哪个量在何时不可用、形成原因是什么 |
| 测量噪声、传感器误差、离群值 | 观测质量或诊断目标 | 哪个量受影响、什么依据说明测量有误、变化属于干扰还是待识别信号 |
| 小样本、弱监督、标签受限 | 支持样本或标注限制 | 标签数量、标签粒度、标签可靠性、类别覆盖与分阶段访问条件 |
| 多工况、非平稳、未见工况 | 运行或分布条件 | 离散工况、持续变化，还是开发到使用时的分布差异 |
| 复合故障 | 多故障同时存在的设置 | 组合覆盖、标注方式及最终输出；不预设多标签损失 |
| 微小/早期故障、微弱故障特征、早检测 | 故障严重度/可观测性或时序目标 | 分开施加的严重度、测量响应、故障演变及实际发出判断的时间 |
| 全流程、多工序、多块 | 对象/尺度及可能的结构 | 具体哪些耦合、传播或异质关系妨碍判断 |
| 间歇过程、多时段运行 | 生产组织与时间结构 | 批次内变化、批次时长差异或质量信息可用性中，哪些实际影响任务 |
| 多源、多模态 | 输入来源/异质性 | 区分运行域、实际采集流、模态和变换视图 |
| 异常定位、根因分析 | 任务/输出 | 要定位什么或解释什么、什么证据能支持 |
| Attention、Graph、Diffusion、Fuzzy、MoE、LLM、慢特征分析、迁移学习 | 候选技术家族 | 从应用段落提取实际问题，不给方法绑定唯一问题 |
| 轻量化/高效模型 | 技术目标或响应 | 边缘端算力、内存、推理时限或实际硬件限制 |
| XAI/可解释性 | 方法/评价主题，也可能来自决策需求 | 谁需要理解哪个判断，用于什么操作或审计 |
| 期刊目录、Review/综述 | 发表来源/文献类型 | 只作检索筛选，不当作问题或方法 |

复合故障可能采用多标签学习，也可能按组合类别或其他明确输出建模；两者不是定义上的等号。MoE也不限于大模型，具体专家和路由设计仍须核对来源。仅整理问题时保持方法未选；作者要求候选方向后，使用[第六节的问题—方法导航](#六作者要求后的问题方法导航)，建立多对多的“问题—候选响应—证据”关系。

## 二、问题用词与边界

以下是条件性描述，不是新增通用模块名。按实际研究选用；外部依据及既有准入范围见[文献索引](published-evidence.md)和[术语库](engineering-application-terminology-bank_CN.md)。

| 现实困难 | 候选英文 | 必须说清的区别 |
|---|---|---|
| 观测不完整 | missing measurements / missing values / incomplete process data | 变量/时间覆盖及形成原因；自然缺失与人为遮蔽评价目标不同 |
| 输入测量不可靠 | measurement noise / noisy process measurements；有依据时用measurement bias | 明确测量量与参考依据；有值但不准确不同于缺失、标注错误和真实过程变化 |
| 不同采样速率 | multi-rate sampling / multi-rate process measurements | 各变量或组具有不同采样时钟，不等于各自间隔不规则 |
| 不等时间间隔 | irregularly sampled measurements | 时间间隔变化，不只是存在多个固定频率 |
| 时间不一致或晚到 | asynchronous measurements / reporting delay / delayed quality measurements | 分开采集时刻、报告可用时刻、对齐与物理过程滞后 |
| 标签稀缺或实测目标稀少 | limited labeled data / label scarcity / sparsely labeled process data | 标注单位、目标、数量；有大量无标签测量时不能笼统说所有数据都少 |
| 粗粒度或不确定标注 | coarse-grained labels / label ambiguity / noisy labels or targets | 标签粒度与可靠性分别描述；候选备选标签不等于多个真实故障共存 |
| 类别支持不均 | class imbalance；确认长尾时用 long-tailed class distribution | 类别数量与受影响类别，不等于小样本，也不是默认卖点 |
| 工况变化/分布变化 | operating conditions；按事实细化multiple operating modes / nonstationary operation / distribution shift | 分清离散与连续变化、开发与使用边界；输入变化本身不证明输入到目标关系的concept drift |
| 过程耦合 | process coupling / interacting production stages / cross-stage dependencies | 已知物理关系与学习关系不同；全流程对象本身不证明耦合困难 |
| 信息来源差异 | heterogeneous process data / heterogeneous sensing / cross-domain distribution differences | 先说明域、采集流、模态、变换视图的实际角色 |
| 多故障共存 | compound faults / simultaneous faults | 故障成员、组合覆盖和输出，不预设具体算法 |
| 故障相关变化微弱 | weak fault signatures；small-amplitude fault perturbations；有定义或明确归属来源的incipient faults | 分开扰动大小、测量响应与实体演变；小特征激活值不等于故障严重度小 |
| 执行资源受限 | limited computational resources / memory constraints / inference-time requirements | 实际设备、资源或时限；少参数不等于实测运行高效 |

题目或引言可按实际限制写quality prediction with limited labeled data，或fault detection from coarse-grained segment labels。这些是表达方式，不是强制题目、已有模块名或创新认证。标注成本、安全限制等原因必须有事实依据，不能代写。核心限制在动机处展开，普通数据属性放在数据/分析部分。

### 间歇过程、批次内时段与质量目标

分开生产批次与训练小批量（minibatch）、批次内时间阶段与物理生产单元，以及训练阶段。文献中的stage/phase用法并非完全一致，应先定义对象，不强行规定唯一译法。数据学习得到的时间分段也不必与工艺操作阶段的边界完全相同。

选择方法前，按实际问题明确：

- **单位与数量：**生产批次数、测量变量数、采样点/窗口数。轨迹展开可产生建模样本，但不增加独立生产批次或实测质量值。
- **时间上的困难：**批次内行为变化、总时长不同、时段边界不同，分别说明。仅填充到等长不代表生产进度已对齐；归一化索引不等于实际经过的时间。
- **目标与可用性：**分开实测浓度轨迹、最终质量值与批次质量类别。最终质量可作为较早训练窗口的监督目标，但不能因此称为各时刻实测质量，也不自动成为预测时可用的输入。
- **决策时点：**完整批次评价与批次运行中的预测可用历史不同。实际结束时间可用于事后对齐，不能悄悄用于更早发出的预测；事先确知的生产计划是另一类输入。核查具体实现时复用[时间边界指南](experiment-evidence-design.md#3-split-integrity-checklist)。

引言只选真正影响任务的困难，不罗列全部字段；结果与讨论将时段/时长效应落到明确的目标和决策时点。批次结束时的准确率不单独证明提前干预能力或产品质量已改善。仅整理问题时，不指定对齐算法、网络或新增实验。

P118 pp.1-3区分单元/时段、数据展开和不等时长；P119 pp.2-4展示最终质量沿时间复制及少批次建模，其案例假设各批等长；P09 pp.3-4、6-7则区分浓度回归与批次类别预测，并讨论长度差异和时段边界不一致。三者是范围明确的例子，不是同一种实现或全部结论认证。中文**多时段**与**多阶段**都用于时间阶段，分别见[自动化学报](https://www.aas.net.cn/cn/article/doi/10.3724/SP.J.1004.2010.00366)及[化工学报](https://hgxb.cip.com.cn/EN/10.11949/j.issn.0438-1157.20180570)的双语题名/摘要；不能据此把所有phase都译成物理工序。

### 微弱故障特征与早检测

微弱故障构成动机时，分开四件事：实际或仿真施加了什么扰动；测量响应如何体现它；是否知道故障的发展轨迹；诊断判断在何时发出。必要时说明幅值对应的量、参考值及单位。小幅输入变化不保证闭环过程的测量响应也小；学习特征的激活值又是另一个量。低信噪比须有信号与噪声定义，不能仅凭两个百分数推定。

P109 pp.7-8的incipient-fault子集包括阶跃、随机变化和阀门粘滞情景；P110 pp.9-10在选定阶跃/随机扰动案例中讨论微弱测量特征及闭环掩盖。它们来自不同团队，但都用TE基准，不是独立现场观测，也不证明所有微小故障必定缓慢增长。保留来源定义的微小/早期故障设置，同时说明当前测试如何实现；固定小幅扰动本身不证明实体退化。间歇性还涉及随时间出现/消失，不等于严重度小或测量值有变化。

引言按实际问题选取“从正常过程波动中区分微弱故障特征”等困难，再衔接已核实的响应；实现细节和待核事项留在相应章节或作者意见中。故障刚发生后的时段、低严重度、发生后的检测时延更短，以及事件发生前预测，是不同主张。复用[既有时间规则](research-planning-and-contribution.md#representation-and-task-boundaries)与[告警证据指南](experiment-evidence-design.md#continuous-monitoring-what-is-scored-and-when)，不为范围准确的分类论文强制增加时序实验。

### 测量质量与诊断信号

使用数据质量标签前，先确定受影响的量及其任务角色。输入测量误差、作为回归目标的化验值不确定性、故障类别标注错误，分别影响研究的不同部分。连续目标本身也可能来自测量，应在目标侧说明其不确定性，不能把所有测量噪声都归为输入损坏。

统计离群说明相对于指定参考不寻常，不直接说明物理原因。过程扰动可以产生真实且正确记录的响应；传感器偏差或卡死，在一项研究中可能是待诊断故障，在另一项研究中可能是输入限制。建议清洗、替换或剔除之前先辨明角色，分开采集质量问题、真实过程动态和新故障类别。

按当前问题只记录受影响的输入/目标、已给参考或已知干预、变量/时段范围及预期判断，原因未知则保留未知。人为加噪是明确的测试条件，不证明原始采集完全无噪声或现场噪声服从同一分布。正文先讲实际困难，再接已核实的响应；收到证据设计请求后复用[抗扰评价指南](experiment-evidence-design.md#6-robustness-design)，不在仅整理问题时指定去噪方法或新实验。

P87 p.8、P88 pp.6-7在规定的加噪条件下评价诊断，P115 pp.4-5则把离群指示用于特征提取。这些语境用于辨明信息角色，不是普遍剔除离群值的规则、结果认证或完整模块名准入。复用既有测量噪声等描述性用语，不由此新增中文复合机制名。

### 观测可用性与计数

观测不完整或时间不一致构成实际困难时，先记录本问题需要的事实。既有采样/掩码指南已有相关区别；此处提前用于问题分类，不先选方法或实验。

| 字段 | 只记录影响本问题的内容 |
|---|---|
| 原生采样 | 物理量、时间单位、原生采样安排与预期采集次数；分清原本不规则和规则采集后的丢失 |
| 可用时刻 | 采集/所代表时刻、发布时刻及决策时刻；分开报告晚到、测量不可用与物理过程滞后 |
| 输入身份与集合 | 物理变量ID/单位、各配置的变量成员及对应关系；分开新增/退出测量、应采却丢失的值与单纯列重排 |
| 模型网格 | 哪些位置实际采集，哪些为保持、插值、填充或未安排采样；实测零值仍是观测 |
| 范围与单位 | 受影响变量、区间或对象；分子/分母统计的是测量值、窗、事件还是持续时间 |
| 来源 | 真实采集限制与人为遮蔽；已知原因和未知项，不凭掩码形态判定统计缺失机制 |

共同网格上的空白未必是一次应采却失败的测量：慢采样时钟可能本来就未安排采集，也可能已有测量但在决策时尚未发布。后续取得的数据可以支持明确声明的延迟估计，不能倒写成早先决策已可用。收到的观测间隔不均，也不能单独区分原生采样不规则和规则采集后的丢失。

分开生成器参数与实际缺失比例。缺失段起点个数除以序列长度，不等于缺失测量条目比例；段长、重叠、边界截断和受影响变量都有关。比较百分比前明确分母是预期采集、全部网格位置、仅受影响变量还是全部变量；有明确掩码时统计实际比例，描述不足时不补造。

P73 p.3第三节A/图1区分采样组的观测与空白网格；P24 pp.2-3讨论采集间隔变化，不只是多个固定时钟；P37 p.6第三节B明确缺失段起点比例并另控段长，该段不核定代码的重叠/截断处理或实际条目比例。这些是不同观测角色，不新增共同模块名，也不认证实验结果。

上述细节放在工作概况或数据/设置部分。摘要、贡献及引言承接只选择真正影响判断的限制，再连到已核实的响应，不罗列每项时钟/掩码；问题-only请求不授权插补、新预测器、指定训练范式或新实验计划。

### 输入变量与采集配置变化

采集配置变化时，先确认各配置中实际存在什么物理变量，以及哪些变量进入过模型开发。等宽向量可以包含不同变量，不同列序也可以仍是同一组变量；应采值丢失又是另一种情况。把它们放进同一数组，不等于含义相同。

P63 pp.2-3在顺序诊断中区分传感测量的新增、退出与缺失；P66 pp.3-4通过已观测变量类型构成的明确集合，表示不同输入子集。两种发表语境支持核对输入身份，不准入共同模块，也不证明任意未来新变量均能处理。已知配置的汇总建模和随时间变化的输入，须分别交代实际开发/使用边界。

引言的问题表述宜正面连清困难与要求。例如事实相符时，可表述为：采集配置改变了诊断可用的变量，而偶发采集失败使应采测量未被观测；利用这些配置的数据需要保留物理变量身份，并区分结构性输入差异与缺失值。这只是承接示例，不是固定句式或新方法主张。详细配置清单、缺失率分母和未测试的未来变量范围，除非正是核心问题，放在设置或作者说明，不逐项塞入动机。新输入变量本身不等于新故障类别。

### 工况变化与跨工况问题

工业条件优先用`operating conditions`，按事实选择搭配：变工况可用`under variable operating conditions`或`under varying operating conditions`，不同工况比较可用`under different operating conditions`；明确涉及随时间变化时用`under time-varying operating conditions`；开发边界未覆盖的工况可用`under unseen operating conditions`，另交代访问条件。

P10 p.1直接使用variable搭配，P81 p.1使用time-varying与varying搭配。这是实际用例，不是全领域词频排名，也不引入它们的方法。此处优先operating，不把operational conditions一概判错，也不改写正确的operational state；`operating varying`不是所需修饰顺序。只写varying conditions而指代不清时补足operating；state、mode、condition仍按真实对象区分。

分开工况变化、故障类别空间和目标数据访问；三者可以并存，本身不选定算法。

| 已知事实 | 可以支持的表述 | 仍需依据的主张 |
|---|---|---|
| 负载、产品等级、配方、场地或明确工况不同 | 实际工况差异；按声明未参与开发时可用unseen operating conditions | 哪个分布改变、物理原因及时间变化方式 |
| 按时间排列的观测具有变化的统计性质 | 非平稳或明确的时序分布变化 | 突变/渐变/重现及变化量；误差变大本身不是漂移检测器 |
| 出现拟合分类器类别集合外的故障 | 相对于该集合的未见/未知故障类别 | 能拒识、能辨认其具体类型或自动学习新类 |
| 已知故障成员出现新组合 | 指定组合划分下的未见故障组合 | 新的故障成员或任意组合泛化能力 |
| 拟合、模型选择或适应时已有新工况数据 | 实际信息访问设置 | 是否用标签、哪些预测发生在访问前后 |

产品等级可能是工况条件，也可能是预测目标，先按任务确定角色再判断是否作为域。未见工况可以保留全部已知故障类，熟悉工况也可能出现新故障。出现新类不等于模型已能拒识、命名或学习它；定义了未知类任务时可保留open-set惯用名，但结果须有证据。

先核时间顺序，再写变化速度或持续适应。多工况与非平稳不互为反义：即使各工况内统计关系稳定，工况切换或出现频率改变也可使汇总分布变化。没有时间安排的跨工况划分不证明渐变轨迹；正常动态响应或单个离群点本身也不证明分布变化。误差上升不自动归因为设备老化、传感器退化或实体机制改变。

明确分布方向与保持条件：`P(X)`是所定义输入的分布；`P(Y)`是目标分布，分类时对应指定类别比例；`P(X|Y)`是给定目标/类别的输入分布，`P(Y|X)`是给定输入的目标关系或分类后验。它们受联合分布约束，不是彼此独立的标签。输入分布改变而`P(Y|X)`稳定时，类别比例也可能改变；仅看到类别比例改变，不能断定满足`P(X|Y)`固定的label-shift设置。两个条件方向不能互换。

P30 p.2第二节式(2)将conditional drift限定为`P(Y)`固定、`P(X|Y)`改变。保留该来源约定，不把它推广成唯一概念漂移定义，也不声称所有条件分布必然改变。事实不足时采用描述性用词，不通过换一个更强名词补足证据。

仅在本问题需要时补充：工况变量及其任务角色、比较边界与时间顺序、故障类别/组合空间、拟合/选择/适应/预测的目标数据访问、实际明确或支持的分布变化及保持条件，以及原因/时间/新类别的未知项。不据此强制新实验或选定适应、拒识、持续学习等方法。

P30的过程问题、P27 p.2的环境水质问题、P50 p.2的源侧开发到未见工况设置、P51 p.1及第二节B的未知故障目的，分别支持不同问题角色；不是同一完整机制的双定义准入，不认证性能，也不解除P51既有阈值约定疑点。新中文复合机制名不由这些描述产生。

### 资源与决策时限问题

分开真实容量约束、决策时限和比较目标。轻量化是设计目标，edge说明执行位置，online说明访问/执行方式，real-time须对应明确时限，四者不相互证明。纯方法研究可以合理比较参数量，不替它虚构边缘设备，也不为正确的参数比较强制硬件试验。

按本研究需要核对：受限的是算力、常驻/工作内存、能耗、通信还是响应时间；预算/时限来源是设备规格、决策流程、服务要求、已测瓶颈还是作者声明的比较目标；约束作用于训练、更新、生成还是预测；哪些组件、请求、模型、激活、缓冲和工作区同时常驻；计时起点、输出对象及相关预处理/排队/传输/后处理；证据是解析成本、模拟成本、设备测量还是接入运行。未知预算不补成具体数字。

采样周期不自动等于决策时限，模型前向时间不等于端到端响应，吞吐量不等于单请求时延。重叠流水段或内存不能重复相加；已明确不重叠时应包含相关各项。单次记录可证明本次超时，不能证明所有负载下的最坏界；输入均已在声明截止时刻获得时，迟发是时间问题，不自动构成未来信息泄漏。

问题可以是保留诊断/预测效果同时满足已有运行预算，也可以是比较研究中的准确率—模型规模权衡；按真实研究选用，保留有依据的积极结果。不由此强制压缩、卸载、稀疏路由、统一毫秒阈值或新实验计划。

P31 p.10是复杂度/训练成本语境，P45 pp.7-8报告设备推理/资源比较，P85 p.7式(16)定义模拟服务中的多部分端到端时延；不是可互换的设备测量，也不新增通用机制准入。源公式和收益均未在此复现认证。

## 三、训练样本、标注信息与学习目标分开描述

训练样本、测试样本是数据实例，应按实际单位计数；任务标签、实测目标、自构造目标及损失约束是不同的学习依据。机器学习里的`training signal`可指学习指导，不等于训练样本，也不一定指物理传感信号。介绍工业研究时优先写清具体对象，不把这些词机械互换。

先问任务标签有什么，再问学习目标怎样构造；下列类别可以组合，**不互斥**，不是完整系统的唯一标签。

| 术语 | 应说明什么 | 不能由名称推出什么 |
|---|---|---|
| supervised learning / 有监督学习 | 用于拟合的任务目标、单位与来源；可以是类别，也可以是连续质量值 | 标签足够多且正确、没有辅助目标或能识别未见类 |
| semi-supervised / semisupervised learning / 半监督学习 | 有任务标签与无任务标签样本实际共同参与学习，说明针对哪个输出及使用阶段 | 仅存放未使用无标签数据就足够；必须伪标签或独立预训练 |
| weakly supervised learning / 弱监督学习 | 不完整、粗粒度、歧义或不准确中的具体限制，以及采用的定义 | 固定标签比例、完全没有监督或永远排除半监督 |
| unsupervised learning / 无监督学习 | 哪个拟合阶段不用外部任务目标；选择、阈值、簇解释及评价如何用标签另列 | 整个过程没有人工知识、簇编号就是故障名称 |
| self-supervised learning / 自监督学习 | 从数据/变换构造的目标、实际损失、联合/分阶段训练及保留预测路径 | 是弱监督/无监督的总称、必须对比学习或全流程无标注 |

[周志华基础综述](https://doi.org/10.1093/nsr/nwx106)的广义弱监督分类包括不完整监督，半监督位于其中；其他社群常较窄地用弱监督指粗粒度或不可靠标注。因此以实际标注条件为准，不建立唯一强制分类树。

工业实质语境：P17 p.2第二节定义稀疏连续化验目标；P21 p.3第三节A把有标签分类与自构造时序目标联合训练；P26 p.3第三节把采样变换预测与有标签分类结合。P22 p.3第三节A明确窗级标注与时刻级输出不同，即使每窗有标签也不等于每时刻有标签。P19 p.6第三节D的聚类目标不用任务标签，但不据此认证调参、簇解释也未用标签。P20 p.3说明人工数据标注，pp.4,6说明自监督训练角色，不把局部训练目标推广为开发/评价全程没有标签。以上是定点阅读，不是全实现或结果审计。

正常数据建模应记录正常性如何确定、拟合使用什么目标、阈值如何设定。保留来源约定的unsupervised detection名称，同时说明影响主张的筛选/选择信息，不凭重构损失判断全系统监督性质，也不统一改名所有正常数据检测研究。

## 四、小型标注概况

只填写本任务已知字段，不为局部写作生成无关清单：

```text
目标/输出及标注单位：
标签数量与覆盖（类别、工况、时段、场地）：
标签粒度（时刻、窗、事件、产品、批次等）：
标签可靠性和目标来源：
可用且实际使用的无任务标签测量：
已明确的学习目标/训练约束、联合或分阶段安排：
拟合、模型选择、适应及最终评价的数据/标签访问：
影响术语判断的未知事实：
```

不设置few-shot/半监督的统一样本数或标签比例。目标域无标签、具有语义说明的未见故障类无实测训练标签、整个开发过程无标签不是一件事；不能都称zero-shot。同批次的相关窗口和合成视图不增加独立实测标注批次数。

## 五、仅整理问题的交付

输出现实困难、条件性中英文用词、已知任务/尺度、观测及标注概况和少量待核事实。方法未选则写“Method: not selected”，证据未给则写“Evidence: not supplied”。不选择论文范式、不推荐网络或唯一算法、不设计新实验、不启动idea工作流。后续获得要求后再补候选方法与对应证据，不把目录共现当成唯一解决关系。
