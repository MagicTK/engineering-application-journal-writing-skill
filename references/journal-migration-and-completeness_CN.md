# 期刊迁移与完整性

用于已授权的转刊、章节整合或压缩审计。调整呈现方式时，不得暗中改变任务、实验或证据。[英文对应版](journal-migration-and-completeness.md)。

## 区分权威要求与样本观察

在目标期刊官网核实适用于当前文章类型和投稿阶段的最新作者指南。记录来源、访问日期及具体要求，与作者偏好、内部目标分开；无法核实时明确不确定性。已发表论文展示的是写作选择，不是编辑部规定。TSMC: Systems 或 Transactions on Cybernetics 的样本均不能代表所有 IEEE 期刊的统一风格。参考文献数量、页数目标、指标公式数量和重复次数都不能被普遍化。按作者最新授权偏好替换已失效的内部建议，但不得歪曲出版方要求。

## 先盘点，再压缩

锁定权威源码与基线 PDF，备份获准编辑的文件。盘点活动正文中的章节、定义、假设、公式、数据集、划分、指标、表格、图片、图注、引用及证据边界。将活动内容与注释、归档结果、未完成作者备注区分开。对每项实质内容记录：保留、改写、迁移及具体去向，或删除及理由。注释块不等于已发表的补充材料。恢复旧数据规模、设置和分数前应核查来源，不能混用实验版本；同时核查表图及依赖结果的正文。

## 重建论证

将 Related Work 融入 Introduction 时，围绕工程要求组织段落：既有研究的前提、相关证据或能力、范围明确的未解决问题，再接本文响应。引用紧贴其支持的主张。保留近邻方法之间的区别，既不粘贴文献目录，也不笼统声称前人忽略整类关系。保留必要边界，但不在各处重复限定。

独立 Problem Formulation 可用于澄清输入单位与维度、已给定的分区或先验、可用标签、预测目标和必要假设。开头把工业困难连接到这些对象；结尾指出尚待解决的建模要求，由 Method 总览接续回答。除非定义任务所必需，实现算子留在 Method。避免通用教材铺垫、重复模块清单，或为新增章节编造理论。章节位置按需要选择，不是整个期刊的统一规定。

## 压缩而不丢含义

先提高段落精度、删除重复解释，再考虑为页数目标删除定义或证据。保留或恢复理解结果所需的指标定义，包括逐类、宏平均、按类别支持数加权的区别，以及分母为零时的处理。适当时可合并公式或改用无歧义文字；既不自动删除所有常规指标，也不机械保留每个公式。保持已批准的字号、数值、表格几何和浮动体锁。迁移确需改变版式时，先获得相应授权并建立新锁，再调整排版。

## 报告真实重复次数

P、R、F1、Acc. 只能在定义后用于缩短标签。缩写不保证 mean±SD 数值能排下；提出获准的版式调整前，应渲染实际表格。优先找回既有逐运行记录。逐项说明实际 n、种子、划分是否固定，以及检查点选择方式。不能为迎合偏好次数重标已完成运行，也不应仅为统一次数要求新增实验。报告逐运行指标均值时，先各自计算再平均，不能用平均精确率和召回率反推平均 F1。样本 SD 的分母为 n-1，单次运行无法定义。区分波动（SD）、均值的不确定性（SEM），以及须说明构造方法的置信区间。

明确声明的合并预测分析也可以成立：先汇总规定的预测/计数，再计算指标。F1等非线性指标不必等于逐运行指标均值；每次预测数量相等时，accuracy两种汇总可能相等。不能仅为数值一致而擅改已确认的汇总对象。同一测试样本的重复预测是运行×样本记录，不是新增独立采集样本；两种汇总都须保持类别顺序、权重、支持数和分母定义。

先说明变化来源是固定数据上的训练初始化、交叉验证折，还是独立生产单元。P66图4标明五折SD，并非五次独立种子运行。折间SD可以作描述统计，但训练折重叠不自动提供推断区间所需的独立重复。按实际主张选择不确定性分析，不强制统一次数、重采样方案或显著性检验。

配对比较应保留真实配对键，并在相应设计下分析逐运行/区组差值。两种方法各自的均值和SD不足以确定差值的波动，协方差同样有关；不能分别排序后配对，也不能仅凭列表等长或种子编号相同补出合理配对。SD误差棒重叠不是显著性检验。均值差的置信区间须有构造与抽样假设，不等于任一方法的SD。可以直接报告有据的较高均值，不自动升级为显著领先或跨工况鲁棒性。

## 让不确定性表达匹配图形

重复敏感性实验的每个点应固定其他设置，在已有条件允许时使用一致种子组，并说明实际 n 和选参所用数据划分。离散设置用误差棒，趋势可用标识清楚的阴影带；明确展示的是 mean±SD、SEM 还是 CI。重复鲁棒性实验的各强度、效率图中的性能轴同样适用；固定参数量无需运行波动误差棒。百分数尺度的 SD 使用百分点。

混淆矩阵和 t-SNE 应说明代表运行的选择方式，优先预定种子或基于验证集的规则，而非选择最好看的测试图。矩阵说明归一化方式，嵌入图说明样本、提取层及投影设置。不能平均互不对应的二维嵌入；跨运行矩阵汇总须另行定义聚合方式。架构和工艺示意图无需统计误差棒。最后核对图注、表格、图片和正文，再编译并检查获准的交付包。

- Song 等，*Addressing Heterogeneous Time-Frequency Causality: Source Consistency Exploring for Industrial Root Cause Alignment and Diagnosis*，Transactions on Cybernetics（2025），[DOI](https://doi.org/10.1109/TCYB.2024.3515174)，刊页1108-1110：第二节问题与动机先于方法。该文研究根因诊断，其因果主张不能迁移到普通分类任务。
