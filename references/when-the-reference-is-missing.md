# What Can This Study Actually Score? / 没有真值时，论文还能验证什么？

Read only the route that matches the engineering decision. Missing **readings**, missing **event labels**, missing **class identities** and missing **physical causes** require different papers, comparisons and conclusions. The following manuscript fragments are fictional. They assume exactly the facts in each example. Experimental designs are suggestions, not completed work.

## 1. Reconstructing an unrecorded reading / 仪表断采

**Literature move.** The [TCYB imputation study](https://doi.org/10.1109/TCYB.2022.3167995), PDF p.7, Table I and metric definitions, constructs gaps by rate reduction or contiguous loss and scores entries with retained reference values. The [TNNLS process study](https://doi.org/10.1109/TNNLS.2025.3527581), PDF pp.6–9, Table I and Figs.6–7, compares conventional and learned estimators at different missing rates, and plots predictions against reference readings as well as errors by variable. Transfer the **availability of a reference**, not their numerical rates or settings. Neither makes the true value of an actual uninstrumented outage observable.

**From the abstract into the introduction.** Suppose the task is a retrospective audit of a dryer; some pressure records were lost, with no backup gauge. *“The dryer audit requires a pressure history, but the recorder has gaps during production. For those intervals no independent pressure measurement is available.”* Paragraph two can now review interpolation and learned estimates **for this retrospective use**. End with the unresolved evaluation issue: *“Error on isolated withheld readings does not establish accuracy over a sustained outage.”* Do not attribute that limitation to a cited study which already tested block outages. 中文：“干燥过程的事后核查需要连续的压力记录，但生产期间存在断采，且断采时没有备用仪表。可以在保留了实测值的时段检验估计误差；真正断采时的压力则不能用同一种办法核实。” The challenge is the duration and lack of a reference, not the absence of a transformer.

**Definition → method → experiment → conclusion.** Distinguish originally observed entries, values artificially hidden from the estimator, and genuinely unobserved entries. Fit normalization and learned imputers on training runs; generate evaluation masks on held-out runs without discarding the hidden originals. Compare a simple fill or interpolation with the learned estimator on identical gaps, rates, channels and information horizons. Centered interpolation is a fair retrospective comparator when all methods may use later readings; it is not a deployable baseline for a past deadline. Test a gap-length distribution separately from the overall missing fraction. Report per-variable errors in stated units on withheld references; a pooled normalized error needs explicit scaling. A trace through a real outage may show an estimate, not a measured trajectory. With an independently calibrated second gauge, report its overlap, time alignment and uncertainty before making a separate natural-outage claim.

## 2. An alarm without fault labels / 没有故障标签的告警

**Literature move.** [Kong et al., TII](https://doi.org/10.1109/TII.2021.3078192), PDF pp.5–6, explicitly train on normal data. [Ulmer et al.](https://digitalcollection.zhaw.ch/server/api/core/bitstreams/33a0acbe-c6d2-4f75-ae3b-7f3af43a8456/content), Secs.3–4 and Fig.3, instead evaluate scores for refining a potentially contaminated pool; the clean reference has privileged access and their experiment is not a subsequent detector deployment. For alarm scoring, [the TNNLS study](https://doi.org/10.1109/TNNLS.2024.3371109), PDF pp.8–9, uses a threshold and point adjustment; [the TII weak-supervision study](https://doi.org/10.1109/TII.2024.3523591), PDF pp.6–7, uses validation labels to select a threshold and omits point adjustment. These results do not share an evaluation protocol merely because both report F1.

**Two openings for different facts.** If operators certify stable production intervals: *“Approved operating runs provide examples of normal pump operation, but no fault episodes are available for fitting.”* If the unreviewed archive may contain faults: *“The pump archive contains pressure histories without event annotations. Unrecognized faults may therefore enter the data used to establish a reference for normal operation.”* 中文：“经确认的正常运行记录”不同于“未经判读的历史记录”；没有逐点故障标签不能证明训练记录全正常。Move from the selection or contamination assumption to the pressure score; only then introduce the alarm rule. A reconstruction target obtained from a measured channel is not an expert fault label.

**Compare decisions, not names.** With the same scorer/backbone compare unfiltered training against the proposed treatment; add certified-normal training only when available, and flag its extra information. Keep threshold calibration, training labels and blind evaluation labels in **three separate fields**. For an unannotated calibration block a score quantile fixes a fraction above threshold there; it is not a known false-alarm probability in contaminated production. Do not select the best test F1. If only incident-level logs exist, match alarms to verified incidents with a declared tolerance, count missed incidents and state which periods have verified event-free exposure. Do not count every unreviewed hour as normal. If verified negatives or sufficiently complete surveillance are absent, report alert frequency/workload, not a false-alarm rate. A score trace can mark independently reviewed episodes; blank intervals are “not reviewed,” not negative. Training-pool separation, test-event detection and confirmed fault-type diagnosis are three different contributions.

## 3. New operating conditions, new faults, or both? / 新工况和新故障是否同时变化？

**Literature move.** [Unseen-condition diagnosis, TCYB](https://doi.org/10.1109/TCYB.2025.3581309), PDF pp.2,6, distinguishes unavailable target-domain data from adaptation. [Imbalanced open-set generalization, TCYB](https://doi.org/10.1109/TCYB.2025.3531494), PDF pp.6–8, separates a known-class decision and unknown states; its T12 discussion explicitly notes both a speed change and additional unknown classes. A distinct endpoint appears in [semantic zero-shot diagnosis, TFS](https://doi.org/10.1109/TFUZZ.2024.3363708), PDF p.3: attributes are matched to descriptions of unseen classes. A rejection flag provides no such identity.

**Build the paragraph around the object that changes.** *“A new feed recipe changes the conditions under which the existing fault classes must be recognized. The inspection policy also allows a case to remain unclassified when none of the known faults fits.”* 中文：“新配方改变的是运行工况，未必改变故障类别。若任务还要求将不属于已知类别的样本交给人工复核，则需要另外评价拒识能力。” The first sentence motivates condition transfer; the second introduces a **separate decision**, not a synonym for the first. First state whether target-recipe records, labels or descriptions reach fitting, calibration or model selection. Do not label a study source-only when even unlabeled target traces set the threshold. If only later maintenance labels name a new class, that defines a later learning phase, not earlier zero-shot recognition.

**Suggested discriminating design.** Cross familiar/new condition with known/held-out fault type. Put independent production runs in each available cell, mark unavailable combinations, and fit thresholds before the held-out test. For known classes give recognition and rejection errors by condition; for unknowns with verified binary status give rejection rates, not unseen-type classification accuracy. A combined cell alone cannot separate effects of a condition shift from class novelty. A four-cell figure with counts, scores and “not observed” is more honest than an averaged curve through an empty cell. A threshold-free ranking result and an operating-point result answer different questions.

## 4. Explaining an alarm or identifying the initiating fault? / 解释告警还是定位起因？

**Literature move.** [Song et al., TCYB](https://doi.org/10.1109/TCYB.2024.3515174), PDF pp.10–12 and Tables IV–VI, distinguish agreement between two inferred sources from agreement with the stated reference, including a source-alignment ablation. [A hierarchical root-identification study, TSMC](https://doi.org/10.1109/TSMC.2025.3646249), PDF pp.6–8, evaluates relations, units and variables and uses the first responding variable as a reference in a process example. That convention is not independent physical confirmation of the initiating defect.

**Carry the evidence level across sections.** *“Several sensors may change after a valve sticks. A variable that strongly influenced an alarm is a candidate for inspection, but its ranking alone does not identify the initiating fault.”* 中文：“阀门卡涩可能引起多个测点变化。对告警贡献最大的测点可以作为巡检线索，却不能据此断定该测点就是故障的物理起因。” Only use a specific valve as a factual explanation in a real paper if the initiating event is documented. If the endpoint is model reliance, compare the effect of masking ranked versus matched control channels and discuss off-distribution inputs. If it is physical localization, use independently verified interventions or maintenance findings at the stated unit/component resolution. Score rank or hit-at-k over episodes with that level of truth, with candidate-set size and coverage; set-valued or ambiguous references need a declared matching rule. Label a temporal ordering or expert plausibility check as such. Do not compare sensor-level rankings directly with equipment-level records without a justified mapping. Agreement of two learned branches is not two independent sources of ground truth.

## 中文组会：把段末的难点带进实验

Two checks before returning prose: name the **object** that stopped (a recorder gap does not mean production stopped). For recipe, machine and class changes, tabulate the observed combinations before attributing an effect. If the new recipe occurs only on the new machine, the old recipe might still run on both. A same-machine recipe contrast or a same-recipe machine contrast is possible wherever both levels actually occur under comparable conditions; distinguishing the interaction across both levels requires the corresponding crossed support. If combinations are not specified, ask or state the comparison conditionally. Do not assume either complete overlap or complete confounding.

写成“记录仪断采”，除非确有停车记录，不改写成“设备停机”。同理，“新配方只在新机组上运行”不等于“新机组只运行新配方”。旧配方是否在新机组运行，决定能否在该机组内比较配方。不必为每个局部比较强行要求完整四格；但不能从几格齐全的局部比较声称已测出所有交互效应。

**Author handoff / 返给作者的问题。** Ask for the one fact that changes the claim: “Which missing entries have a reference?”, “Who certified the alarm-free intervals?”, “Which unknown types can actually be named at prediction time?”, or “What independently identifies the initiating component?” If unanswered, return the narrower sentence and the proposed check separately; never turn the proposed check into an accomplished contribution.
