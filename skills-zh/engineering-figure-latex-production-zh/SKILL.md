# 工程应用论文图表与 LaTeX 生产

套件版本：`4.1.32`

## 一、任务目标

生成可编辑、可核验、与工程论证一致的科学图表和稳定 LaTeX 交付包。

## 二、锁定版本与构建边界

识别权威源码、基线 PDF、图片与参考文献目录、内容/数据/排版锁、受保护表格字号和浮动体顺序、编译命令及输出目录。未知脚本、包或 `shell-escape` 需求先审查，不把编译产物放入 Overleaf 上传目录。

## 三、指定科学作用

先明确图表的科学作用，例如动机、过程/数据生成、整体框架、模块细节、主对比、消融、敏感性、鲁棒性、解释或工程结果；混合图按 panel 区分。读取[图表与 LaTeX 指南](../../references/figure-and-latex-production.md)，实质生成前使用 [`figure-table-contract.md`](../../assets/templates/figure-table-contract.md) 记录必要约束。

非实测的整体框架、算法流程、系统结构、motivation 和机制示意图，选择能保留科学结构及所需可编辑源件的可用工具。[AstraDraw → 可编辑 PPT → 人工修订 → 论文闭环](../../references/astra-editable-figure-pipeline.md) 是可选路线，不是安装前置条件。实测/结果依赖 panel 使用真实数据和可复现绘图；混合图逐 panel 分流。已有可编辑主件的局部对象修改直接从当前主件续做。

## 四、保护证据真实性

- 结果依赖图必须使用真实、可追溯数据。
- 示意图只能表达已确认工艺事实，不编造设备、信号和运行关系。
- 明确区分物料流、数据流、控制流、学习关系与因果方向。
- 注意力、嵌入和热力图只能按其定义解释。
- 保留原始素材和生成草稿的替换映射。
- 视觉接受、科学核验、执行授权和发布权限分别记录，并绑定版本。

## 五、面向最终印刷尺寸设计

根据科学信息量选择单栏或双栏；保证无需放大即可阅读；统一 panel、术语和颜色语义；删除无意义内嵌标题和重复图例；优先使用可编辑矢量图和可复现绘图；生成式草图插入前逐项核对技术标签。

真实字体、保留源图的局部修改和作者选定的纯色风格，按需读取[设计与局部修改规则](../../references/figure-and-latex-production.md#3-visual-design-rules)。本套件不指定通用字体或色板，具有科学含义的色图、纹理与透明度按实际用途保留。只交付 PNG 或只改局部不授权新增格式或全图重建。模型身份和固定维度若定义了方法本身，应保留，不能用泛化标签暗示未经确立的兼容性。

作者选择可选重建路线时，读取[依赖、编辑与批准规则](../../references/astra-editable-figure-pipeline.md)及[修订状态记录](../../assets/templates/figure-revision-state.md)。人工改稿成为当前主件；原生可编辑实测、渲染效果与公式源可用性分别核验。批准绑定版本和范围，已有授权不反复确认；依赖缺失如实说明，不将受阻阶段记为完成。

## 六、保守处理表格

保留作者确认的字号、分组、指标顺序和强调。表格过宽时，在授权排版范围内先考虑已定义表头的缩写及列宽分配。删除列、拆分科学问题或转入补充材料须提出建议并获授权，不能为凑页删掉证据；也不能先用极小字号或整体缩放。

## 七、编译与逐页目检

每次实质改动后：

1. 在 Build check 中编译；
2. 检查未定义引用、缺图、warning 和 overfull；
3. 渲染 PDF；
4. 逐页检查，包含实际纸面大小的图及受影响页、相邻页、裁切、caption 位置和绕排文字终止；
5. 与基线对照受保护页面和浮动体；
6. 核对 caption、正文、表格和参考文献。

LaTeX 无报错不等于排版和科学内容通过。

## 八、整理交付目录

保留一个明显的 Overleaf 上传目录、一个最新编译检查目录、独立 Supporting files/research notes 和历史 Backups。上传包默认只保留一个图片目录。使用 [`author-handoff.md`](../../assets/templates/author-handoff.md) 记录源码/PDF、受阻项、作者输入、受保护内容和结果联动修改位置。

修订图还需交付当前可编辑主件及指纹、人工批准依据、scene/manifest/映射同步状态、公式 LaTeX、资产与字体来源、最终尺寸预览和对照、可编辑实测、导出至 TeX/PDF 的精确映射。缺失源件与待办如实标明；可移交的 Overleaf 文件集不代表已上传远端。

## 九、质量门

- 无结果图编造；
- 图语义与公式、正文一致；
- 图稿按类型分流，实测图仍由已核验的真实结果数据绘制；
- 可编辑性声明有原生对象实测，并披露公式和图片限制；
- 人工修改保存在当前主件中，批准与论文导出绑定该修订版；
- 最终字号可读；
- 表格样式与排版锁未破坏；
- 浮动体顺序支持叙事；
- 无大面积异常空白、孤立标题、重叠或裁切；
- 上传包无编译垃圾和重复图片树；
- 交接清单覆盖所有替换项和作者任务。
