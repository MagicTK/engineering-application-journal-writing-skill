# 工程应用论文图表与 LaTeX 生产

套件版本：`4.1.2`

## 一、任务目标

生成可编辑、可核验、与工程论证一致的科学图表和稳定 LaTeX 交付包。

## 二、锁定版本与构建边界

识别权威源码、基线 PDF、图片与参考文献目录、内容/数据/排版锁、受保护表格字号和浮动体顺序、编译命令及输出目录。未知脚本、包或 `shell-escape` 需求先审查，不把编译产物放入 Overleaf 上传目录。

## 三、指定科学作用

每个图表必须属于动机、过程/数据生成、整体框架、模块细节、主对比、消融、敏感性、鲁棒性、解释或工程结果之一。读取[图表与 LaTeX 指南](../../references/figure-and-latex-production.md)，并先填写 [`figure-table-contract.md`](../../assets/templates/figure-table-contract.md)。

非实测的整体框架、算法流程、系统结构、motivation 和机制示意图，选择能保留科学结构及所需可编辑源件的可用工具。[AstraDraw → 可编辑 PPT → 人工修订 → 论文闭环](../../references/astra-editable-figure-pipeline.md) 是可选路线，不是安装前置条件。实测/结果依赖 panel 使用真实数据和可复现绘图；混合图逐 panel 分流。已有可编辑主件的局部对象修改直接从当前主件续做。

## 四、保护证据真实性

- 结果依赖图必须使用真实、可追溯数据。
- 示意图只能表达已确认工艺事实，不编造设备、信号和运行关系。
- 明确区分物料流、数据流、控制流、学习关系与因果方向。
- 注意力、嵌入和热力图只能按其定义解释。
- 保留原始素材和生成草稿的替换映射。
- 视觉接受、科学核验、执行授权和发布权限分别记录，并绑定版本。

## 五、面向最终印刷尺寸设计

### 可选纯色结构图与真实字体核查

以下视觉细则仅适用于作者选定的纯色几何结构图风格，不是所有期刊的规则，也不能据此替换认可的图稿。字体、色板和格式服从期刊与作者；本套件不要求某一种字体。定量色图、真实纹理及具有科学含义的透明度应按各自用途处理。

- 画布、卡片和每个色块只用纯白或一个固定纯色；每段文字使用固定字色。禁止水墨、氤氲、粉底、涂抹纹理、渐变、阴影、发光以及字后白色光晕。正常边缘抗锯齿可以保留；同一对象内部不能变透明度。作者允许透明时也必须使用恒定透明度。
- 标题、小字、边框及局部箭头使用所属模块的同色系深色或黑色；明确承载数据身份的颜色按定义保留。作者指定成熟深蓝时禁止鲜蓝、电蓝替代。热力图数值可对应不同颜色，但单格内部必须均匀。
- 新排文字及作者要求替换的公式应使用指定的真实字体文件。生成式PNG的近似字形不算字体已核验。合同指定Comic Sans MS常规与Cambria Math时，应核对实际字体face、字号、字符覆盖与数学上下标；不得以模拟手写体或过重标题替代。
- 修正视觉时保留科学信息量和既定拓扑。后续重建PPT时，一个对象应使用一个简单固定填充，不能叠加装饰图层仿造栅格阴影。
- 每轮累计继承已接受约束；以原生尺寸和预期阅读尺寸实查空白底、单元格内部、字形内核/边缘、标题、公式与图例。提示词写对不等于图片达标。

### 保留原图几何的局部修改

当作者认可既有结构而只要求修正颜色或字体时，锁定原坐标、宽高比、紧凑间距、连线端点和走向、箭头头部比例、标注、运算符号以及内部示意几何。不能为统一颜色或追求可编辑而整体重建。聚类点云、采样标记与虚线、小型示意图、冻结/可训练符号都承载信息；应保留其排列。作者授权程序编辑栅格图时，重建会退化的区域直接复用原图裁剪，做局部掩膜与改色，并如实说明其栅格属性。

已认可色板决定颜色，已认可源图决定几何，当前论文决定科学语义。较早图稿存在的公式、掩膜、访问条件或箭头错误，须把当前科学修正局部迁回，不能随视觉回退恢复。作者要求箭头减轻，不等于箭头应缩至难辨；应对照参考箭头的杆/头比例和最终阅读尺寸。

数学观感不仅由字体名称决定，还取决于常规/粗体、变量斜体、运算符正体、上下标、求和符号大小、基线、间距与居中。真实字体须由源文件证明，不能凭PNG猜测。作者认可原图字形时可保留，仅替换确有问题的局部；字源不明应记录未核验，而非因此强制全图重排。采用作者最新字体决定，不沿用被替换的项目默认值。

论文与配图共同修改时，先稳定权威正文并分配动机图、总览图、模块细图角色，再改图。检查局部前后对照和整体构图；可行时核验受保护区域像素。结果依赖图等待真实数据。仅PNG或要求裁剪保真的授权优先于下方可选PPT流程，不能为了流程一致性新增格式或整体重画。

根据科学信息量选择单栏或双栏；保证无需放大即可阅读；统一 panel、术语和颜色语义；删除无意义内嵌标题和重复图例；优先使用可编辑矢量图和可复现绘图；生成式草图插入前逐项核对技术标签。

作者选择上述可选路线时，按照闭环指南和 [`figure-revision-state.md`](../../assets/templates/figure-revision-state.md) 完成全流程：

1. 发现并读取当前安装的 `astra-figure-workflow`（AstraDraw）；依据论文设计、迭代并记录真实设计决策。
2. 发现并读取当前安装的 `image-to-editable-ppt`（Image to Editable PPT）；对选定设计进行对象级重建，保留源 manifest、资产和图号/页号映射。
3. 检查交付稿渲染，并在副本上实测原生文字、图形和连线编辑。声明图片与公式的例外：矢量公式加 LaTeX 源码不等于 Office 原生可改公式。字体和字形来源必须有源件依据，不能凭 PNG 外观猜定。
4. 交付可编辑源件供作者/学生审阅和人工修订；收到人工改动后登记为当前主件。再次从源件编辑前对账已过期的 scene/JSON/对象映射，禁止从旧输入重建覆盖人工修改。
5. 将批准绑定当前修订版和范围，再导出或截图该主件，集成已授权的本地 TeX/Overleaf 文件集，编译并按实际纸面大小检查图及受影响页、相邻页。

尚未人工确认就保持待确认；同范围已有明确确认不反复询问。当次请求可授权连续多阶段或委托选择设计，记录真实授权而不宣称发生了人工审阅。缺失技能/运行时须说明并继续不依赖它的科学契约工作。维护 Skill 不授权安装或转换；实际已授权转换按已安装技能、当前用户约束和运行时权限执行。

## 六、保守处理表格

保留作者确认的字号、分组、指标顺序和强调。表格过宽时，在授权排版范围内先考虑已定义表头的缩写及列宽分配。删除列、拆分科学问题或转入补充材料须提出建议并获授权，不能为凑页删掉证据；也不能先用极小字号或整体缩放。

## 七、编译与逐页目检

每次实质改动后：

1. 在 Build check 中编译；
2. 检查未定义引用、缺图、warning 和 overfull；
3. 渲染 PDF；
4. 逐页检查，包含实际纸面大小的图及受影响页、相邻页、裁切、caption 位置和绕排文字终止；
5. 与基线对照受保护页面和浮动体；
6. 核对 caption、正文、表格和参考文献。

LaTeX 无报错不等于排版和科学内容通过。

## 八、整理交付目录

保留一个明显的 Overleaf 上传目录、一个最新编译检查目录、独立 Supporting files/research notes 和历史 Backups。上传包默认只保留一个图片目录。使用 [`author-handoff.md`](../../assets/templates/author-handoff.md) 记录源码/PDF、受阻项、作者输入、受保护内容和结果联动修改位置。

修订图还需交付当前可编辑主件及指纹、人工批准依据、scene/manifest/映射同步状态、公式 LaTeX、资产与字体来源、最终尺寸预览和对照、可编辑实测、导出至 TeX/PDF 的精确映射。缺失源件与待办如实标明；可移交的 Overleaf 文件集不代表已上传远端。

## 九、质量门

- 无结果图编造；
- 图语义与公式、正文一致；
- 图稿按类型分流，实测图仍由已核验的真实结果数据绘制；
- 可编辑性声明有原生对象实测，并披露公式和图片限制；
- 人工修改保存在当前主件中，批准与论文导出绑定该修订版；
- 最终字号可读；
- 表格样式与排版锁未破坏；
- 浮动体顺序支持叙事；
- 无大面积异常空白、孤立标题、重叠或裁切；
- 上传包无编译垃圾和重复图片树；
- 交接清单覆盖所有替换项和作者任务。


### 可选纯色风格细化

仅在作者选定纯色几何风格时应用。下面的具体字体只是需核实可用性、许可及作者选择的例子，不是所有工程论文的推荐字体。

纯色空白抽检不足以验收。必须检查重要对象的整圈边框及连接线：边为精确直线，直角或圆角规整，边框颜色与粗细固定，虚线段长与间距一致；消除弯曲、褪色、擦抹感，不能只把旧歪线换色。修补已登记边框带时保持原坐标、端口及科学小图；仅在确需连接的端口留口。圆、三角、方块、坐标轴保持轮廓均匀及原有位置、间距和数量。

每个对象一个固定填充、一个边框色，每段同语义文字一个固定墨色。清除紧贴文字和框线的残留晕染，而不只检测卡片空白处。禁止素描、手写墨迹、粉笔、水墨、粉底、阴影、光晕、纹理线、柔焦边、变化透明度。新增文字和箭头从透明图层做alpha合成，使用实际底色，禁止白色贴片边。仅正常边缘抗锯齿允许覆盖度变化。模块内数据流箭头随所属模块深色系；跨模块无法合理归类时可用黑色。

选用此清新正式风格时，标题、小标题、卡片文字与正文均加载真实Gill Sans MT常规字体，不加粗；层级通过字号、留白和协调色系区分；Futura可作有价值的备选。核验实际字体face；数学使用真实数学字体、变量斜体、算子正体。不能将生图相似字形当作指定字体已核验。先保存修好的现版本，再制作白底浅色正式候选，不继承过时Comic默认。大块白底、小操作框极浅纯色即可；参考图的手绘纹理不属于必须继承的结构。

方法图显示准确类别，如时序基础模型、大语言模型，确属多模态时才用多模态基础模型。具体模型/检查点及数值实例维度放实验设置；方法用符号维度并说明兼容接口。换名称不等于任意骨干都可替换或跨模型效果已有实证。

生成前检查有效提示词及继承模板，去掉要求sketch/comic/hand-drawn/brush/chalk/wash/gradient/shadow效果的正向描述；明确工程期刊正式图、精确直线/圆角几何框、均匀线宽、固定填充/边框/字体色、主要块白底、模块同色箭头、无装饰特效。锁定科学小图和端口。实际逐对象检查框、字底、阶段标识和箭头；有具体缺陷就定点修正，不为精确文字反复全图生成。
